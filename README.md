# 咸潮 SALT TIDE

> 中式民俗海洋恐怖 · 类《死魂曲》（Siren）第一人称潜行 Demo
> 约 20 分钟可玩流程 · Three.js（WebGL2）· 全程序化资产（零二进制文件）

一九八几年，东南沿海的盐门村在一场没做完的「锁潮祭」之后，被永远钉在了涨潮前的那个傍晚。
村民的喉咙里灌满海水，却还在补网、晒盐、巡堤、点香——三年了，一天都没停过。
你叫陈潮生，回村给母亲上坟。渡船停航，你从礁滩涉水上岸。
广播还在响。灶还是温的。歌，从海的方向来。

---

## 快速开始

需要 Node.js ≥ 18。

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

或构建后运行：

```bash
npm run build
npm run preview      # 打开 http://localhost:4173
```

低配机器 / 软件渲染环境可加参数降载（关阴影与泛光、降分辨率）：
`http://localhost:5173/?lowspec=1`

## 桌面版（Windows EXE / Linux AppImage）

Vite 构建产物通过 Electron 打成桌面单文件包，**双击即玩，无需安装 Node**。

**下载现成的包（推荐）**：GitHub Actions 工作流 `desktop-build` 在推送到 `main`、
手动触发（Actions 页 Run workflow）或打 `v*` 标签时自动构建。进入仓库
**Actions 页 → 最近一次 desktop-build 运行 → Artifacts**，下载：

- `SaltTide-win-portable-exe`（Windows 便携版 `SaltTide-<版本>-win-portable.exe`，双击直接运行，无需安装）
- `SaltTide-linux-AppImage`（Linux 版，`chmod +x` 后直接运行）

推送 `v*` 标签时会自动把两个包挂到对应的 GitHub Release 页。

**本地打包**（任意平台，Linux 上也能交叉打出 Windows exe）：

```bash
npm install
npm run dist          # 同时产出 Windows 便携 exe + Linux AppImage → release/
npm run dist:win      # 只打 Windows 便携 exe
npm run dist:linux    # 只打 Linux AppImage
npm run desktop       # 不打包，直接以桌面窗口运行（开发用）
```

产物在 `release/` 目录（约 100 MB，含 Chromium 运行时，故不入库）。
桌面版以 1280×720 窗口启动，`F11` 切换全屏，`Esc` 仍为游戏内暂停菜单。

## 操作

| 按键 | 动作 |
|---|---|
| `W A S D` | 移动 |
| 鼠标 | 视角 |
| `Shift`（按住） | 潜行（降低身形与噪音） |
| `Q` | 视奸：切入他者的眼睛；再按切换信道；长按/再按 `Q` 或任意移动键退出 |
| `E` | 互动（拾取文书 / 点香 / 推门 / 合闸 / 爬梯 / 敲铃） |
| `Esc` | 暂停菜单 |

**没有武器。被潮尸抓住＝死。** 死亡从最近检查点重来。

## 核心机制

- **视奸（Sightjacking）**：按 `Q` 借用潮尸、村犬、海鸟、望海者的眼睛侦察。切入时有调谐噪点、
  信道标签与**信号强度条**（越近越清晰），载体的呼吸带动镜头起伏与桶形畸变。
  **每种载体有专属视野**：犬视低矮偏色、快喘；鸟瞰广角俯冲；歌唱者视野泛红、脱色；
  望海者几乎不呼吸，只有海。两处主线必须靠视奸推进：
  1. 堤门钥匙——借巡堤人的眼睛，看他每晚检查钥匙藏在哪；
  2. 锁潮祭次序——借祭师的眼睛，看他反复演练的点香顺序（肉眼看不见的「鬼火」只在他的视野里亮）。
- **潮尸不是丧尸**：他们维持着生前的劳作（补网、晒盐、巡堤、守殿、唱咸歌）。惊动之后会执着追踪、
  绕「最后目击点」螺旋式搜索、并且**永远记得你**（警觉底线只升不降）。被追上不是黑屏——
  是一段**近身抓住演出**：他扑过来掐住你，镜头被拖进他涨水的喉咙。
- **歌唱者（红衣）**：不追人。但靠近她的歌声会积累「共鸣」——屏幕右侧的竖式计量管开始灌水，
  歌声带立体声定位，脚下有**可见的歌声涟漪**一圈圈荡开，涨满即溺毙于自己的喉咙。听声辨位，绕开。
- **威胁方向指示**：被盯上时屏幕边缘出现一道血色弧光，指向最危险的那双眼睛——
  弧光越亮越窄，他离扑过来就越近。
- **望海的人**：礁滩与沉船湾的浅水里立着几个不动的身影，面朝海。血潮起时，他们会一齐转过来面向村子。
- **血潮（中段高潮）**：取走喉铃后整片海变成暗红，水位上涨，礁滩与晒盐场被淹，劳作者起身巡游，歌唱者与守塔人入场——同一张地图，规则全变。

## 20 分钟流程节拍

1. **礁滩搁浅**（电影运镜开场：从夜海俯冲到搁浅者睁眼；潮汐电台 + 遗物文书①；任意动作键可跳过）
2. **石堤渔寮**：潜行教学 → 堤门上锁 → 视奸巡堤人得知钥匙 → 开门（文书②③）
3. **村中心/晒盐场**：广播站（文书④），两名巡游者之间穿行
4. **潮母宫**：视奸祭师看鬼火次序 → 按序点香（北→南→中）→ 请下喉铃（文书⑤⑥）
5. **血潮**：海变红、水上涨、敌人换班，去灯塔的路只剩沉船湾
6. **沉船湾**：走龙骨桥，绕开歌唱者的共鸣半径
7. **灯塔**：合电闸 → 塔灯亮 → 爬上塔顶（文书⑦⑧）
8. **终局**：把喉铃挂上敲响 → 海平线站起来 → 强制视奸（从海的眼睛看塔上的自己）→ Demo 结束

环境叙事：全图共 **8 条文书**（船票、家书、祭簿、电台抄件、碑文、电报……），拼出锁潮祭失败的真相。

## 技术栈与取舍

- **Three.js 0.185 + Vite**：Linux 云环境无 GPU 也能用 SwiftShader 无头验证；WebGL2 实时渲染。
- **零二进制资产**：所有贴图（木纹/石墙/盐霜/瓦/皮肤/衣物/水法线）用 Canvas 程序化生成——
  分级分辨率（主视觉 1024² / 中景 512² / 小件 256²，低配减半），每张贴图同步生成
  **颜色 + 法线 + 粗糙度**三件套（木节疤/石凿痕/灰泥剥落/盐霜结晶/尸皮静脉纹都在像素层刻画）；
  所有模型（建筑套件/人形/沉船/灯塔）程序化建模；所有音频（海床/风/潮歌/脚步/铃/船螺）用
  WebAudio 实时合成。仓库只有代码。
- **渲染**：ACES 色调映射、UnrealBloom、胶片颗粒、暗角、轻微色差、桶形畸变（视奸/濒死）、
  分离调色（阴影压蓝青/高光提暖）、指数雾 + 贴地雾片、fbm 分层云 + **云后月盘/血月** +
  远海闪电叉（延迟雷声）、程序化等距柱状**环境反射贴图**（血潮时整体换成暗红反射）、
  PCF 软阴影、PBR 材质（法线 + 粗糙度贴图）、动态水面（顶点波 + 滚动法线 + Fresnel +
  浪尖白沫 + **近岸浅水色与拍岸白沫带** + 血潮脉动与海面磷火）、体积光锥（灯笼/塔灯）、夜灯呼吸式闪烁。
- **AI**：状态机（劳作/巡逻/起疑/追击/搜索/归位/抓住），视锥 + 视线遮挡 + 听觉半径，
  噪音事件总线，最后目击点螺旋搜索 + 驻足环视。
- **动画**：关节层级 + 程序化步态/劳作/歌唱/抓扑姿态、喉咙吞咽脉动、头部抽搐（无关键帧文件）。
  潮尸按种子做**个体差异**：跛行程度、脊柱歪斜、垂头角度、步频各不相同；
  肿胀躯干、破渔网披、盐结晶、外露肋线与静脉皮肤在建模与贴图层同时表达。
- **音频**：全 WebAudio 合成——海床低频、风、潮歌（立体声方位跟随）、材质化脚步（湿滩/石板/沙）、
  铃、船螺、电台、心跳/溺水共鸣、潜行呼吸层、追击喉音、抓住铜锣、远雷。

## 项目结构

```
docs/            设计文档 + 美术圣经
src/
  core/          引擎壳(渲染/后处理)、输入、程序化音频
  world/         程序化贴图、材质、几何合批、地形与渔村大地图、水面、天空
  entities/      玩家控制器、程序化人形、潮尸AI、村犬、海鸟群
  systems/       视奸、潜行威胁聚合、叙事导演(文书/触发器/检查点/终局)
  ui/            HUD(字幕/目标/文书/暂停/死亡/结局)
scripts/         无头浏览器验证(构建→启动→截图→按20分钟节拍自动通关)
```

## 自动化验证

```bash
node scripts/verify.mjs smoke        # 渲染与移动冒烟测试
node scripts/verify.mjs looks        # 关键场景与角色外观 + 视奸信道 + FPS（FULLSPEC=1 全画质）
node scripts/verify.mjs gameplay     # 机制抽查（视奸/警觉/死亡重生/点香/血潮）
node scripts/verify.mjs playthrough  # 全流程通关（视奸/谜题/血潮/灯塔/终局，逐节拍断言）
```

截图输出到 `verify/`。全流程脚本会断言每个主线 flag（`knowKeySpot`、`puzzleSolved`、`bloodTide`、`breakerOn`、`ended`……）并确认结局遮罩显示、全程零控制台报错。
