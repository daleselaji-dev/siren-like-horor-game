一九九八年，蚀湾填湾造地，石头是从湾底捞的。老石匠说那不是石头，是「床板」。
镇里跟海立了约：借地三年。二〇〇一年秋，今夜「核册还地」——
全镇到南方大酒店吃最后一顿还地饭，报数员逐户念名，念到的把手放在册上。
潮来了，但水没有来；来的是深度。楼是干的，屋子却开始承受深海的时间。
你是外乡人。周絮写信求你来做核册的「外证」——名字不在镇册上的人，才有资格看着册子合上。
旧俗里有一条没人告诉你：册末留着一行空名。
外乡人走了，镇上不用挂白。

## 快速开始

需要 Node.js ≥ 18。

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

或构建后运行：

```bash
npm run build
npm run preview      # 打开 http://localhost:4173
```

低配机器 / 软件渲染环境可加参数降载（关阴影与泛光、降分辨率）：
`http://localhost:5173/?lowspec=1`

|---|---|

| `Shift`（按住） | 潜行（降低身形、噪音与振动） |
| `Q` | 视奸：切入他者的眼睛；再按切换信道；任意移动键退出 |
| `E` | 互动（文书 / 推门 / 合闸 / 播放母带 / **破像**） |
| `F` | **镁光闪**（海鸥牌相机·消耗镁光泡）：看见光的人捂眼定身，追踪断线 |
| `G` | **发条闹钟**（消耗）：上弦放地上，九秒铃声把听得见的人钓过去绕圈 |
| `V` | **贝灰线**（消耗）：脚前倒一道界——守规矩的东西不肯踩过去 |
| `R` | **录音对照**（手提录音机）：回放磁带；在**录下它的地方**放，能听出对不上的那一处 |

**没有武器。被抓住＝被「引座」回宴席的空椅。** 从最近检查点重来。

## 核心机制

- **视奸（Sightjacking）**：按 `Q` 借用镇民、侍应、保卫、报数员、浮客、回眸客的眼睛侦察。
  每种载体有专属视野滤镜（报数员俯瞰全宴会厅、浮客视野上浮、回眸客多重曝光）。
  主线两处必须视奸：镇口栅门门闩（岗亭员的眼——看他盯着的闩才知道闩在里侧）
  与宴会厅侦察（报数员的眼）。
- **CRT 预现**：镇里和酒店的 CRT 不播现在——播**这个空间的下一个稳定形态**。
  屏幕里比现实多的东西即将出现。服务走廊、保卫科九宫格、807 电视都是侦察窗口。
- **破像**：对预现画面中的关键结构动手（合闸、扯下「還」字金匾），让现实与录像不符——
  该次预现作废。被屏幕「点名」（画面里你坐进了空椅）后，破像是唯一解。
- **核册议程时钟**：报数员广播推进全镇状态：起雾→收港→归屋→**验户（返潮点火）**→熄灯→还地。
  每次切换前全镇**收声两拍**。议程可拖延，不可取消。
- **反击工具（资源制，无枪）**：海鸥牌相机的**镁光闪**（`F`，看见光的人捂眼定身、追踪断线，
  镁光泡散在照相馆皮套/暗房/筒子楼里）、**发条闹钟**（`G`，上弦两秒半、响九秒，
  把听得见的人钓去绕钟筛查——追击中看不见你的人也会被拐走）、**贝灰线**（`V`，理骨用的
  贝灰倒一道界，追击者到界前站定不肯踩过）。工具在箱庭里捡，用一件少一件。
  三件对**上宾**也各有一手：镁光让它当场摆回「丈量姿态」定格数秒（板条排直、绳牌垂稳），
  闹钟的铃能把那条房间尺度的手臂钓离你的地板，贝灰界前它的掌会悬住——不肯越界，只肯等。
- **录音对照（箱庭侦探环）**：2F 棋牌室的手提录音机 + 散在录像厅、海洋馆值班桌的三盘磁带。
  按 `R` 平放只有沙沙的底噪和标签提示；带到**录制它的地方**回放，能听出录音与眼前对不上的
  那一处（带子里数出九副碗、桌上只摆八副……），每处对上都点亮一个藏奖励的暗格。
- **保险丝分闸（黑暗是行装）**：配电间总闸旁的分闸板管大堂/西翼/客房层三路灯。
  瓷底保险丝可以拔下来揣走、插到别路——断电的堂口灯全灭，你站在暗处所有眼睛的视程打六折；
  代价是你自己也只剩一双肉眼。备餐间纸箱里藏着第四枚备品丝。后勤线走应急电，这块板管不着。
- **世界状态切换（薄雾 → 返潮异化）**：验户点火后整座镇被重排——履职的镇民一个不剩，
  主街被海底顶上来的**沉积脊**封死（泥壳里嵌着别人家的门），街心摆出**面海椅阵**
  （三十把椅子全脸朝海，每把上一双叠好的鞋），脊脚下堆起整夜放雪花的 **CRT 冢**；
  去酒店要么钻**床单巷**（湿床单挡视线不挡人=有掩护的潜行道），要么绕盐田空旷西线。
  街上巡走的换成**湿客**（五员：主街缝隙/西环/湾岸/家属楼院/盐田道）：不认贝灰的界、
  镁光定身减半——耳朵灌了水，反而最吃闹钟那一套。
- **幻潮面（里世界的天）**：异化后牌坊以内的镇子上空 11.5 米悬着一层**没有水的海面**——
  焦散光网缓慢地流，鱼的影子分群绕圈，一条极大的影子绕全镇一圈要三分多钟；
  拴船的缆绳从街面绷直向上，玻璃浮子顶在潮面底下。整镇材质同拍「泡透」
  （街面砖木瓦十种材质变暗偏冷、粗糙度减半、出湿反光），认领过的街面留一串镜面水洼。
  **洼是窗**：低头看任何一块镜洼，洼里倒着天上那层潮——光网在洼底流，
  鱼影从洼里游过；巨影经过你头顶的同时，也经过你脚下（模板缓冲平面反射，带真视差）。
- **噪声与振动**：地面材质决定传声——瓷砖水磨石传远，红毯吸振。
  上宾段落里振动条涨满即被点名：**红毯是安全带**。
- **规则怪谈（三条，均可玩可违反）**：
  ① **广播响起时不许看向海的方向**——镇喇叭响的几秒里视线朝海超过约两秒，
  强制视奸切入「海的信道」并被引座；背过身或进屋即可豁免。
  ② **CRT 里出现你，必须在倒计时内破像**——被九宫格「点名」后 75 秒倒计时，
  超时引座；砸闸破像即解除。
  ③ **侍应托盘空着时不要让他看见你的手**——渗漏态后空盘侍应见到站立的你直接警觉；
  蹲伏（收手）通过即无事。规则由镇口告示墙与员工手册（文书⑨⑩）明文教学。
- **核册与小镇工位**：报数员（口部钙化封死，声先于手势）、侍应（浮木颈臂，抓住你＝引座）、
  理册婆（镜中早一拍、倒退走）、回眸客（残影指针）、浮客（脚尖离地半寸）、
  上宾（房间尺度木板前肢，板间无肉，从不吼叫）、岗亭员（投币口状嘴缝，守栅门永不离岗）、
  理骨员（胶皮围裙骨刷，只听骨头不听人）、周絮（盐霜附居痕迹沿半张脸不对称蔓延——
  她在被慢慢腌成礁石）。全部不可杀，只能读懂并绕开。
- **上宾的读法（2m 内）**：板上挂三层悬摆——湿麻绳吊红漆「界」牌、宴会厅拆下的红绸、
  捆在中段板下的红白丈杆；板缝里**木屑簌簌往下掉**（这条手臂始终在解体）；
  指节缠着褪色红布、掌缘还留着宴会圆桌的铜包边。它数到你的时候，
  四根手指丢掉各自的相位**同拍敲地**，一下，一下；手到七步之内，
  绳端的「界」牌会缓缓拧过来朝向你——先点到名的是牌。
- **上宾首见演出**：破像那一拍，大堂挑空的天花先响一声（钉子退出旧木料的响）——
  八节臂板、半张桌掌、十二件指节共 21 件旧料**逐块从顶棚剥离、翻着跟头凌空拼进臂位**，
  每件落位一声闷木响；垂绳与红绸等宿主板落位才挂出来。它不是走进大堂的，
  是大堂自己拼出来的。
- **巨影过顶低鸣**：幻潮里那条 13m 的影子游近头顶时，一声从胸腔下面顶上来的持续低鸣
  （31Hz 基频+失谐倍频，26m 内平方渐起、正过顶满值）——它没有出声，
  是「深度」压过你头顶的那种响。

## 主线节拍（镇口 → 前街 → 街心 → 酒店 → 海洋馆 → 灯塔）

1. **末班车到站**：2001 年夜班长途车把你放在镇口车站——开场首拍前两秒是**车内视角**
   （坐姿视高越过司机的肩，雨刮一躬一躬扫挡风玻璃，扫开的水又立刻蒙回来），
   随即硬切站台低机位仰拍（电影运镜：车灯扫过牌坊后驶离）；站台长椅取行李得外证凭条（文书①）
2. **过栅门**：牌坊下栅门落闩在里侧——视奸岗亭里的岗亭员，看他盯着的闩杆才知道怎么开
3. **镇前街**：政府告示墙读《夜间告示》（文书⑨，规则①②明文）；磁卡电话亭响铃；
   杂货铺公告栏（③核册告示）、广播站（④值班记录）——通宵录像厅的雪花屏一直亮着
4. **规则一实战**：镇喇叭巡播时背对海走；违反＝强制切入「海的信道」被引座
5. **入酒店**：满员大堂登记簿（⑤）；上 807 照影房见周絮拿手镜；服务走廊 CRT 教学；
   员工手册（文书⑩，规则③）
6. **验户＝返潮点火**：收声两拍 → 全楼渗漏态、**镇区异化**（主街封脊/椅阵面海/湿客上街）；
   空盘侍应段落（规则③）；保卫科九宫格点名 → 75 秒倒计时（规则②）→
   合配电闸破像 → 海洋馆钥匙（⑥）
7. **巨物厅与母带**：穿西馆连廊入主展厅——房间尺度的「未定种」骨架半埋沉积床，
   绕开理骨员巡线，处理间铁柜取母带（⑦）；巡检记录（文书⑦号位）
8. **终局**：807 播母带揭示空名规则（⑧）→ 理册婆倒退镜面追逐 → 宴会厅大破像 → 灯塔结算；
   堤门滩涂支线可拾渔民日记（②）

## 技术栈与取舍

- **Three.js 0.185 + Vite + Electron**：无 GPU 云环境用 SwiftShader 无头验证；WebGL2 实时渲染。
- **资产管线**：贴图（水磨石/矿棉吊顶/墙纸/缎面/浮木/沉积/盐霜……）全部 Canvas 程序化生成，
  颜色+法线+粗糙度三件套；场景模型（小镇建筑/三层酒店/海洋馆/工位人形）全程序化建模；
  音频（海床/点名谣/报数员广播/收声/材质化脚步/木板呻吟/CRT 蜂鸣）全 WebAudio 合成。
  在此之上，五件**英雄细模**（车站守夜人/橱窗立像/迎宾侍应/床单巷湿客/无面海神像）
  走 **Blender 4.1.1 headless 管线**（bpy 脚本生成 → .blend → Cycles CLI 渲染验证 →
  gltfpack meshopt 压缩 GLB → `?inline` base64 内联进 bundle），
  每件 2 万上下三角面 + 1024 球面展开程序化皮肤贴图，压缩后约 125KB/件。
  GLB 内联使 dev / 无头验证(http) / Electron(file://) 三端同一条加载路径，零运行时网络请求。
- **渲染**：ACES、UnrealBloom、胶片颗粒、暗角、轻色差、指数雾、程序化云月、
  动态水面（渗漏态深绿黑切换）、PCF 软阴影、PBR 材质。室内光全部来自灯具
  （荧光管频闪/钨丝吊灯/门头灯箱/CRT 荧光），**无恐怖蓝滤镜**。
  模板缓冲平面反射（幻潮镜洼：水洼写模板、镜像潮网/鱼影限洼绘制，
  镜洼潮网透明度/贴图偏移与头顶真网同一口潮息）；
  开场湿镜头（格胞水珠倒像折射+珠缘冷高光，落回眼睛后约五秒收干；
  开场零拍两秒车内视角里这层水珠读作挡风玻璃的雨——雨刮扫过被抹开一瞬又蒙回）。
- **远景窗内假房间（interior mapping）**：窗洞填充不再是涂黑铁皮——片元里按视线与
  虚拟房间盒求交（后墙/地板/天花/侧墙，世界空间切线架，合批后成立），逐房哈希两成
  暖灯/八成黑屋，后墙家具暗带+竖条柜帘明暗；换装到酒店四条窗带、家属楼北墙、民房
  侧窗与录像厅山墙高窗。街面散布密度层：七条散布线沿街缘撒杂草簇（7 支细锥合并、
  单材质合批）+纸屑/塑料袋/木碎/排水口绿瓶——2001 年县镇的街不是扫干净的舞台。
- **建筑立面（反盒体）**：坡顶逐垄瓦筒+脊瓦、封檐板+出挑椽头、博风板、真三角山墙收口、
  窗套（楣/台/边梃/十字棂）、门头雨檐双斜撑；商铺檐口线脚+女儿墙压顶+门脸山花+铸铁落水管；
  酒店层间腰线+逐窗窗台/滴水+空调锈痕。
- **灯光预算**：全图点光按相机距离排序同屏只开 16 盏（低配 10），防止前向渲染灯光爆炸。
- **人物近景管线（反蜡人）**：皮肤双层法线——底层法线烘皱纹/斑驳/粗毛孔，
  清漆层第二法线（`clearcoatNormalMap`）平铺细胞噪声毛孔微结构，菲涅尔清漆做皮脂油光
  （失血员工湿、老年干、理骨员几乎无油）；眉毛/睫毛为 alpha 贴片逐根毛；嘴唇独立体积几何
  （双唇峰+唇珠+口裂缝管）配湿润高光材质；面部微动画：左右错拍眨眼（35–90ms）、
  眼球弹道扫视+注视微漂（警戒时死盯）、嘴角单侧抽动、单侧挑眉——酒店员工三件套全部冻结；
  近距 LOD：2m 内换 84×60 段高模头（皮下微起伏）+ 加密法线细节层，2.9m 滞回换回。
- **照片脸皮烘焙（反面具）**：AI 生成参考照按五官标定球面投影进 2048 头皮画布
  （照片标定空间与画布分辨率解耦），眼裂/发际/背景/发丝四重 gate 拒收假像素；
  统频微粒层以 overlay 铺满整头皮——照片区与程序底皮区的毛孔频率在同一层噪声里合流；
  颈裙挂亮度调频贴图+毛孔法线，颌缘不再是「照片皮 vs 塑料皮」的断面。
  湿客潮尸皮走**泡发次表面**：宽瓣冷青肉里光+窄瓣贴体水线（受光门控），
  覆掉活人的暖红透光——轮廓那圈青灰正是「不再是活人」的读法。
- **AI**：状态机（劳作/巡逻/起疑/追击/搜索/归位/引座），视锥+楼层判定视线遮挡+听觉半径、
  最后目击点搜索；上宾走振动感知，理册婆走镜面提前一拍规则。

## Blender 细模管线（bpy → .blend → CLI 渲染 → GLB）

英雄人物与场景关键件不再手搓 three.js 几何，而是在 **Blender 4.1.1（headless，无 MCP）**
里用 bpy Python 程序化建模——放样人体（躯干/四肢/分指手）+ 参数化头雕（单位球场沉积变形：
眉弓/眼窝/鼻/唇带/颏/颌角）+ numpy 直绘球面展开皮肤贴图（骨相阴影/唇色/胡茬/老年斑/
盐霜/溺亡大理石纹），死魂曲读法：**6 米外是普通人，2 米内才读出唯一主异常**
（司仪口部钙化、侍应颈长一档头垂太低、守夜人半脸盐霜、湿客整皮泡发、神像无面）。

```bash
bash blender/install_blender.sh        # 幂等安装官方 Blender 4.1.1 到 ~/blender-4.1.1
bash blender/build_assets.sh r9 48     # 一条龙：生成 → 渲染(轮r9,48spp) → gltfpack 压缩入库

# 或分步：
~/blender-4.1.1/blender --background --python blender/gen_characters.py \
    -- --only emcee,wetguest --glb blender/export        # bpy 生成 .blend + 原始 GLB
~/blender-4.1.1/blender --background --python blender/render_verify.py \
    -- --chars emcee --round r9 --samples 48             # Cycles CPU 渲染验证图
npx gltfpack -i blender/export/emcee.glb -o src/assets/models/emcee.glb -cc -kn
```

多轮迭代对照图在 `verify/blender/`（r1 过曝胶囊 → r2 眼球出窝 → r3 四人成形 →
r4 鞋裤衔接/湿客头身比 → r5 神像 → … → r21 工位件），`.blend` 工程在
`blender/out/`（可打开续雕）。
游戏内运行时装配在 `src/world/heroModels.js`：HeadPivot 转头三读法
（守夜人慢转头 / 湿客极慢 creep / 橱窗立像「被注视即冻结」）、
呼吸微动画（活人才有）、首见字幕、人形碰撞柱、灯光预算接入。
`node scripts/verify.mjs blenderglb` 对五件断言：装配齐 / 细模面数门槛 /
HeadPivot / 转头积分 / 首见字幕 / 湿客返潮点火才到岗。

**工位 GLB（r21·双轨归一）**：宴会厅**舞台报数员**（`emcee_stage.glb` 持麦变体——
与橱窗立像同一张脸）、**三名巡场侍应**（`waiter.glb`）、**理册婆**（`matron.glb`
绾髻/拢手/眉心矿物孔板第三眼）等 gameplay 近景工位不再用程序化 Humanoid，
直接装配 Blender 细模。bpy 导出内嵌关节 pivot 空节点
（TorsoPivot/ArmPivotL/R/LegPivotL/R/HeadPivot——旋转≈基姿、位置即关节点）
与 EyeAnchorL/R 眼锚点；运行时 `src/entities/stationBody.js` 实现与 Humanoid
相同的最小接口（`animate`/`setEyeIntensity`/`headWorldPos`/`neck`/`torso`），
每帧「基姿四元数 × 摆动欧拉」合成步态：侍应传送带碎步+托盘臂锁死、
报数员持麦臂焊死+左臂周期「宣布」、理册婆拢手对等角 X 摆（手对不散）+
倒退步头锁死；眼点冷光挂眼锚点，警戒才亮；键光/轮廓光进灯光预算随人走。
`node scripts/verify.mjs station` 断言：五具身体细模门槛(>9000 tris)/六 pivot 齐/
道具在场(麦头/托盘/第三眼)/**工位禁止胶囊 Humanoid**/步态摆动/托盘锁定/
眼点门控/视奸口径，并落盘 `verify/station/r21_*` 与 `verify/keep/station/` 取证。
