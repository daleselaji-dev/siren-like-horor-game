# 返潮 FANCHAO — M01 垂直切片

> 中国沿海小城心理恐怖 · 类《死魂曲》（Siren）第一人称潜行 Demo
> 蚀湾 · 迎宾楼千禧婚宴酒店 · 2003 · Three.js（WebGL2）· 全程序化资产（零二进制美术文件）

2000 年前后，沿海小城**蚀湾**经历了「第二次失去」：厂子改制没了，千禧内湾工程停了，
海退了三年——今年又漫回来了。镇上叫这个**返潮**：东西受了潮，
本应结束的事，就会重新走一遍。

你姐姐的婚宴定在**迎宾楼**（原水产公司招待所，列入第三批拆除范围）。
十月二十五。她没有出席自己的婚礼。你在拆迁前的最后一夜走进这栋楼。

大堂的灯还亮着一半。员工还在上班。登记簿上，同一场婚宴登记了四遍。

---

## 快速开始

需要 Node.js ≥ 18。

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

或构建后运行：

```bash
npm run build
npm run preview      # 打开 http://localhost:4173
```

低配机器 / 软件渲染环境可加参数降载（关阴影与泛光、降分辨率）：
`http://localhost:5173/?lowspec=1`

## 桌面版（Windows EXE / Linux AppImage）

Vite 构建产物通过 Electron 打成桌面单文件包，**双击即玩，无需安装 Node**。

**直接下载（本仓库内）**：`release/Fanchao-<版本>-win-portable.exe`
（便携版，双击直接运行，无需安装；约 90 MB，含 Chromium 运行时）。

**CI 构建**：GitHub Actions 工作流 `desktop-build` 在推送到 `main`、手动触发或打
`v*` 标签时自动构建。进入仓库 **Actions 页 → 最近一次 desktop-build 运行 → Artifacts**：

- `Fanchao-win-portable-exe`（Windows 便携版）
- `Fanchao-linux-AppImage`（Linux 版，`chmod +x` 后直接运行）

**本地打包**（任意平台，Linux 上也能交叉打出 Windows exe）：

```bash
npm install
npm run dist:win      # Windows 便携 exe → release/
npm run dist:linux    # Linux AppImage → release/
npm run desktop       # 不打包，直接以桌面窗口运行（开发用）
```

桌面版以 1280×720 窗口启动，`F11` 切换全屏，`Esc` 仍为游戏内暂停菜单。

## 操作

| 按键 | 动作 |
|---|---|
| `W A S D` | 移动 |
| 鼠标 | 视角 |
| `Shift`（按住） | 潜行（降低身形与噪音；地毯上脚步更轻） |
| `Q` | 听潮：借入他者的眼睛；再按切换信道；任意移动键退出 |
| `E` | 互动（读文书 / 推门 / 测深 / 播放录像 / 照镜子） |
| `Esc` | 暂停菜单 |

**没有武器。被他抓住＝被「保存」。** 死亡从最近检查点重来——但他记得你。

## 核心机制

- **听潮（Structural Listening）**：按 `Q` 借入附近载体的眼睛——还在上班的员工、
  监控摄像头、以及**他**。每种载体的眼睛不一样：员工的视野疲惫浑浊、随呼吸起伏；
  监控是冷绿的不眨眼广角；他的信道最冷、最清楚——像从井底朝上看。
  切入表现是**水压、耳鸣与呼吸**（本作明令禁用 VHS 噪点撕裂）。
  **代价**：听得越久暴露越深，听他的信道涨得最快；暴露涨满，
  他会在井底察觉——强制反向听潮（他借走你的眼睛），从此他知道楼里有人。
- **Depth（深度异常）**：这栋楼的**里面比外面大**。工程深度尺（保卫室拾取）
  测的不是长度是"深"：图纸上 12.6 米的客房走廊，实测 21.9 米；
  从尽头折返，走廊会当着你的面**再变深**（34.0 米，灯更少、门更多、门牌没有数字）；
  尽头的镜子里，灯的数量和你回头数的不一样。规律可以学：**变深永远发生在你背后。**
- **F01「井身者」王承海**：拆迁清单上唯一没有终止日期的员工。
  **6 米外**他只是一个还在上班的中年人——灰蓝工装、暗红领子、侧分的头发，
  在婚台边把一块桌布擦了又擦。**2 米内**深度尺读数会告诉你不对劲：表面 0.4m，内部 3.8m。
  他的左眼、右眼和口腔各是一口**真实向内的井**（多层几何：反锥井壁 + 递进环圈 + 井底水光，
  不是黑贴图破洞）——井口比井身窄，**里面比外面大**。
  被发现后他不跑：**比走路快一点，比跑慢一点，像去接一个客人**——身后走廊的灯一盏盏灭掉。
  被抓住是一段近身演出：他把你的头捧起来，镜头沉进他左眼的井里。
- **非怪物恐怖 · 婚宴录像**：宴会厅的录像机接着监控屏。播放那盘带子——
  画面是这间厅**十八秒之后**的样子。带子里有个人走进来、停在婚台前、转头看镜头。
  带子放完十八秒后，现实里的脚步声在门口响起，**把录像里的动作原样再做一遍**。
- **员工 AI**：拖地的、巡逻的、切配的——他们维持岗位职责（死魂曲精神），
  起疑会来查看，被惊动后执着搜索、互相通风报信，抓到你是"扭送出门"而非杀死。
- **证据文书**：全楼 8 件文书（登记簿 / 拆迁公告 / 排班表 / 保卫日志 / 进货单 /
  剪报 / 工程注记 / 新娘的信），拼出主题：**失踪的人不是被杀死的，是被「保存」起来的——
  有些人分不清"留住"和"占有"。**

## M01 流程节拍（约 10–15 分钟）

1. **Normal**：前庭海雾 → 推门 → 大堂（还亮着一半的千禧水晶灯）→ 登记簿（听潮教学）
2. **Measure**：保卫室拿工程深度尺 → 监控屏上的时间比墙上的钟快 → 测走廊：12.6m ≠ 21.9m
3. **Leak**：走到尽头折返——走廊在你背后变深；深段尽头照镜子（镜里的走廊更长）
4. **Return**：婚宴厅双门自己开了；员工到点下班，楼里只剩"他"
5. **录像超前现实**：播放婚宴录像 → 十八秒后现实重演 → 婚台上有一封信
6. **F01 Encounter**：拿信 → 他放下抹布朝你走来 → 身后灯一盏盏灭 → 逃出大门
7. **Aftermath**：他停在玻璃门里不出来 → 门口回望 → 灯箱熄灭 → 结局

## 技术栈与取舍

- **Three.js 0.185 + Vite + Electron**：Linux 云环境无 GPU 也能用 SwiftShader 无头验证。
- **零二进制美术资产**：全部贴图（脏白乳胶漆/褪色粉墙纸/抛光砖/婚宴红绒/不锈钢/
  中年皮肤/工装布纹/侧分头发）用 Canvas 程序化生成，每张同步产出**颜色+法线+粗糙度**；
  全部模型程序化建模；全部音频 WebAudio 实时合成。仓库只有代码。
- **雕塑级程序化人体**（诚实边界：目标是《死魂曲》式可读精度 / 主机世代观感，
  不宣称真 PS5 网格资产）：高分段球体/胶囊/Lathe + **高斯特征场顶点位移**雕出
  眉弓、眼窝、鼻梁、颧骨、法令区、下颌线、耳廓、锁骨、小腹、指节；
  主剪影不允许出现裸 Box / 低段 Cylinder。F01 的三口井是**真实向内的多层深度几何**：
  在雕刻头上删除面片开出真孔，孔内接 BackSide 反锥井壁（口窄腹宽）+ 递进环圈 +
  吸光井底 + 水光点——2 米内凑近看，井确实比头深。
- **渲染**：ACES 色调映射、UnrealBloom、胶片颗粒、暗角、轻微色差、桶形畸变（听潮/濒死）、
  分离调色（烟黄高光/灰绿阴影）、指数雾分级（室外海雾浓/室内潮气薄）、
  分形云 + 隔雾的月 + 远海无声闪电（数秒后闷雷）、RTT 监控画面（录像事件与保卫室三屏共用）、
  体积光锥、镇流器老化式灯闪。**禁则已执行**：无蓝水下滤镜、无 Gore、无 VHS glitch。
- **AI**：状态机（劳作/巡逻/起疑/追踪/搜索/归位），视锥+视线遮挡+听觉半径，噪音事件总线，
  最后目击点搜索；F01 追逐永不忘记目标。
- **音频**：全 WebAudio 合成——楼宇低频、海风、材质化脚步（地毯/瓷砖/水洼）、
  日光灯镇流器嗡鸣、门轴、心跳、听潮水压脉冲、追逐鼓点、远雷。

## 项目结构

```
docs/            设计文档 + 美术圣经（《返潮》M01）
src/
  core/          引擎壳(渲染/后处理)、输入、程序化音频
  world/         程序化贴图、材质、几何合批、迎宾楼酒店、天穹海雾
  entities/      玩家控制器、雕塑级程序化人形、F01 井身者、员工 AI、监控摄像头
  systems/       听潮、潜行威胁聚合、叙事导演(节拍/录像事件/文书/检查点/结局)
  ui/            HUD(字幕/目标/文书/暂停/死亡/结局)、标题前庭夜景
scripts/         无头浏览器验证(构建→启动→截图→按 M01 节拍自动通关)
release/         Windows 便携 exe（入库交付）
```

## 自动化验证

```bash
node scripts/verify.mjs smoke        # 渲染与移动冒烟：各厅室传送截图
node scripts/verify.mjs looks        # 员工/F01 六米·两米/井特写/各厅外观/压力锋面/监控信道 + FPS
node scripts/verify.mjs gameplay     # 机制抽查（听潮/员工警觉/死亡重生/文书/走廊变深/暴露）
node scripts/verify.mjs playthrough  # 全流程通关（测深/Leak/录像超前/F01 重演/追逐/井演出/结局，逐节拍断言）
```

截图输出到 `verify/`。全流程脚本断言每个主线 flag（`measured`、`extended`、`videoSeen`、
`replayDone`、`letterTaken`、`escaped`、`ended`……）并确认结局遮罩显示、全程零控制台报错。
