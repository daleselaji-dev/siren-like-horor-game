2001 年秋，沿海县镇蚀湾。填湾造地盖起的南方大酒店今晚办喜事——周家嫁女，全镇赴宴。
潮来了，但水没有来；来的是深度。楼是干的，屋子却开始承受深海的时间。
你是新娘的伴娘，渡船在滩涂搁浅，你迟到了半天。
镇里的电视不播现在，播的是每个房间接下来的样子。
旧俗里有一条没人告诉你：若海不满意新娘，就收影子。
伴娘，就是影子。

## 快速开始

需要 Node.js ≥ 18。

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

或构建后运行：

```bash
npm run build
npm run preview      # 打开 http://localhost:4173
```

低配机器 / 软件渲染环境可加参数降载（关阴影与泛光、降分辨率）：
`http://localhost:5173/?lowspec=1`

## 操作

| 按键 | 动作 |
|---|---|
| `W A S D` | 移动 |
| 鼠标 | 视角 |
| `Shift`（按住） | 潜行（降低身形、噪音与振动） |
| `Q` | 视奸：切入他者的眼睛；再按切换信道；任意移动键退出 |
| `E` | 互动（文书 / 推门 / 合闸 / 播放母带 / **破像**） |
| `Esc` | 暂停菜单 |

**没有武器。被抓住＝被「引座」回宴席的空椅。** 从最近检查点重来。

## 核心机制

- **视奸（Sightjacking）**：按 `Q` 借用镇民、侍应、保卫、司仪、浮客、回眸客的眼睛侦察。
  每种载体有专属视野滤镜（司仪俯瞰全宴会厅、浮客视野上浮、回眸客多重曝光）。
  主线两处必须视奸：镇口栅门门闩（岗亭员的眼——看他抬闩才知道闩在里侧）
  与宴会厅侦察（司仪的眼）。
- **CRT 预现**：镇里和酒店的 CRT 不播现在——播**这个空间的下一个稳定形态**。
  屏幕里比现实多的东西即将出现。服务走廊、保卫科九宫格、807 电视都是侦察窗口。
- **破像**：对预现画面中的关键结构动手（合闸、撬囍匾），让现实与录像不符——
  该次预现作废。被屏幕「点名」（画面里你坐进了空椅）后，破像是唯一解。
- **喜事议程时钟**：司仪广播推进全镇状态：迎宾→入席→上菜→**敬酒（返潮点火）**→上头→送入洞房。
  每次切换前全镇**收声两拍**。议程可拖延，不可取消。
- **噪声与振动**：地面材质决定传声——瓷砖水磨石传远，红毯吸振。
  上宾段落里振动条涨满即被点名：**红毯是安全带**。
- **规则怪谈（三条，均可玩可违反）**：
  ① **广播响起时不许看向海的方向**——镇喇叭响的几秒里视线朝海超过约两秒，
  强制视奸切入「海的信道」并被引座；背过身或进屋即可豁免。
  ② **CRT 里出现你，必须在倒计时内破像**——被九宫格「点名」后 75 秒倒计时，
  超时引座；砸闸破像即解除。
  ③ **侍应托盘空着时不要让他看见你的手**——渗漏态后空盘侍应见到站立的你直接警觉；
  蹲伏（收手）通过即无事。规则由镇口告示墙与员工手册（文书⑨⑩）明文教学。
- **宴席与小镇工位**：司仪（口部钙化封死，声先于手势）、侍应（浮木颈臂，抓住你＝引座）、
  全福婆（镜中早一拍、倒退走）、回眸客（残影指针）、浮客（脚尖离地半寸）、
  上宾（房间尺度木板前肢，板间无肉，从不吼叫）、岗亭员（投币口状嘴缝，守栅门永不离岗）、
  理骨员（胶皮围裙骨刷，只听骨头不听人）。全部不可杀，只能读懂并绕开。

## 主线节拍（镇口 → 前街 → 街心 → 酒店 → 海洋馆 → 灯塔）

1. **末班车到站**：2001 年夜班长途车把你放在镇口车站（电影运镜：车灯扫过牌坊后驶离）；
   站台长椅取行李得喜帖（文书①）
2. **过栅门**：牌坊下栅门落闩在里侧——视奸岗亭里的岗亭员，看他抬闩的手才知道怎么开
3. **镇前街**：政府告示墙读《夜间告示》（文书⑨，规则①②明文）；磁卡电话亭响铃；
   杂货铺公告栏（③婚宴通知）、广播站（④值班记录）——通宵录像厅的雪花屏一直亮着
4. **规则一实战**：镇喇叭巡播时背对海走；违反＝强制切入「海的信道」被引座
5. **赴宴**：满员大堂登记簿（⑤）；上 807 陪新娘上头拿铜镜；服务走廊 CRT 教学；
   员工手册（文书⑩，规则③）
6. **敬酒＝返潮点火**：收声两拍 → 全楼渗漏态；空盘侍应段落（规则③）；
   保卫科九宫格点名 → 75 秒倒计时（规则②）→ 合配电闸破像 → 海洋馆钥匙（⑥）
7. **巨物厅与母带**：穿西馆连廊入主展厅——房间尺度的「未定种」骨架半埋沉积床，
   绕开理骨员巡线，处理间铁柜取母带（⑦）；巡检记录（文书⑦号位）
8. **终局**：807 播母带揭示影子规则（⑧）→ 全福婆倒退镜面追逐 → 宴会厅大破像 → 灯塔结算；
   堤门滩涂支线可拾渔民日记（②）

全图共 **10 条文书**，拼出「许潮」旧俗、三条怪谈规则与影子规则的全貌。

## 技术栈与取舍

- **Three.js 0.185 + Vite + Electron**：无 GPU 云环境用 SwiftShader 无头验证；WebGL2 实时渲染。
- **零二进制资产**：贴图（水磨石/矿棉吊顶/墙纸/缎面/浮木/沉积/盐霜……）全部 Canvas 程序化生成，
  颜色+法线+粗糙度三件套；模型（小镇建筑/三层酒店/海洋馆/人形）全程序化建模；
  音频（海床/喜歌/司仪广播/收声/材质化脚步/木板呻吟/CRT 蜂鸣）全 WebAudio 合成。
  仓库内唯一的二进制是可直接运行的 Windows exe。
- **渲染**：ACES、UnrealBloom、胶片颗粒、暗角、轻色差、指数雾、程序化云月、
  动态水面（渗漏态深绿黑切换）、PCF 软阴影、PBR 材质。室内光全部来自灯具
  （荧光管频闪/钨丝吊灯/门头灯箱/CRT 荧光），**无恐怖蓝滤镜**。
- **灯光预算**：全图点光按相机距离排序同屏只开 16 盏（低配 10），防止前向渲染灯光爆炸。
- **AI**：状态机（劳作/巡逻/起疑/追击/搜索/归位/引座），视锥+楼层判定视线遮挡+听觉半径、
  最后目击点搜索；上宾走振动感知，全福婆走镜面提前一拍规则。
- **CRT 预现**：低分辨率 RenderTarget + 第二相机 + 图层掩码，轮询刷新离玩家最近的屏。
- **人群**：宴会厅满员用烘焙合并网格（一桌宾客一 draw call）。

## 项目结构

```
docs/            设计文档 + 美术圣经（返潮·蚀湾设定）
src/
  core/          引擎壳(渲染/后处理)、输入、程序化音频
  world/         程序化贴图、材质、几何合批、蚀湾小镇、南方大酒店+海洋馆、水面、天空
  entities/      玩家控制器、高保真程序化人形、工位AI、浮客/回眸客/上宾
  systems/       视奸、潜行/振动、CRT预现、议程时钟、叙事导演(文书/触发/检查点/终局)
  ui/            HUD(字幕/目标/文书/议程/振动/暂停/死亡/结局)
scripts/         无头浏览器验证(构建→启动→截图→按八节拍自动通关)
release/         Windows 便携 exe（入库，可直接下载运行）
```

## 自动化验证

```bash
npm run verify                        # 四步全跑
node scripts/verify.mjs smoke        # 渲染冒烟：镇口/前街/家属楼/酒店各层/巨物厅机位
node scripts/verify.mjs gameplay     # 机制抽查（视奸/警觉/引座重生/CRT/议程/振动/上宾）
node scripts/verify.mjs looks        # 外观：镇口车站/牌坊/告示墙/巨骸/工位近景/渗漏态
node scripts/verify.mjs playthrough  # 主线全流程通关：10 条文书 + 三条规则怪谈的
                                     # 违反与遵守双路径逐 flag 断言
```

截图输出到 `verify/`（精选交付图在 `verify/keep/`，人物近景在 `verify/chars/`）。
全流程脚本断言每个主线 flag（`townGateOpen`、`inHotel`、`leaked`、`imageBroken`、
`ruleSeaViolated`、`ruleNameExpired`、`ruleTraySeen`、`hasTape`、`finaleBroken`、`ended`……）
并确认结局结算、全程零控制台报错。
