# 咸潮 SALT TIDE

> 中式民俗海洋恐怖 · 类《死魂曲》（Siren）第一人称潜行 Demo
> 约 20 分钟可玩流程 · Three.js（WebGL2）· 全程序化资产（零二进制文件）

一九八几年，东南沿海的盐门村在一场没做完的「锁潮祭」之后，被永远钉在了涨潮前的那个傍晚。
村民的喉咙里灌满海水，却还在补网、晒盐、巡堤、点香——三年了，一天都没停过。
你叫陈潮生，回村给母亲上坟。渡船停航，你从礁滩涉水上岸。
广播还在响。灶还是温的。歌，从海的方向来。

---

## 快速开始

需要 Node.js ≥ 18。

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

或构建后运行：

```bash
npm run build
npm run preview      # 打开 http://localhost:4173
```

低配机器 / 软件渲染环境可加参数降载（关阴影与泛光、降分辨率）：
`http://localhost:5173/?lowspec=1`

## 操作

| 按键 | 动作 |
|---|---|
| `W A S D` | 移动 |
| 鼠标 | 视角 |
| `Shift`（按住） | 潜行（降低身形与噪音） |
| `Q` | 视奸：切入他者的眼睛；再按切换信道；长按/再按 `Q` 或任意移动键退出 |
| `E` | 互动（拾取文书 / 点香 / 推门 / 合闸 / 爬梯 / 敲铃） |
| `Esc` | 暂停菜单 |

**没有武器。被潮尸抓住＝死。** 死亡从最近检查点重来。

## 核心机制

- **视奸（Sightjacking）**：按 `Q` 借用潮尸、村犬、海鸟的眼睛侦察。两处主线必须靠视奸推进：
  1. 堤门钥匙——借巡堤人的眼睛，看他每晚检查钥匙藏在哪；
  2. 锁潮祭次序——借祭师的眼睛，看他反复演练的点香顺序（肉眼看不见的「鬼火」只在他的视野里亮）。
- **潮尸不是丧尸**：他们维持着生前的劳作（补网、晒盐、巡堤、守殿、唱咸歌）。惊动之后会执着追踪、搜索、并且**永远记得你**（警觉底线只升不降）。
- **歌唱者（红衣）**：不追人。但靠近她的歌声会积累「共鸣」，涨满即溺毙于自己的喉咙。听声辨位，绕开。
- **血潮（中段高潮）**：取走喉铃后整片海变成暗红，水位上涨，礁滩与晒盐场被淹，劳作者起身巡游，歌唱者与守塔人入场——同一张地图，规则全变。

## 20 分钟流程节拍

1. **礁滩搁浅**（开场演出：潮汐电台 + 遗物文书①）
2. **石堤渔寮**：潜行教学 → 堤门上锁 → 视奸巡堤人得知钥匙 → 开门（文书②③）
3. **村中心/晒盐场**：广播站（文书④），两名巡游者之间穿行
4. **潮母宫**：视奸祭师看鬼火次序 → 按序点香（北→南→中）→ 请下喉铃（文书⑤⑥）
5. **血潮**：海变红、水上涨、敌人换班，去灯塔的路只剩沉船湾
6. **沉船湾**：走龙骨桥，绕开歌唱者的共鸣半径
7. **灯塔**：合电闸 → 塔灯亮 → 爬上塔顶（文书⑦⑧）
8. **终局**：把喉铃挂上敲响 → 海平线站起来 → 强制视奸（从海的眼睛看塔上的自己）→ Demo 结束

环境叙事：全图共 **8 条文书**（船票、家书、祭簿、电台抄件、碑文、电报……），拼出锁潮祭失败的真相。

## 技术栈与取舍

- **Three.js 0.185 + Vite**：Linux 云环境无 GPU 也能用 SwiftShader 无头验证；WebGL2 实时渲染。
- **零二进制资产**：所有贴图（木纹/石墙/盐霜/瓦/水法线）用 Canvas 程序化生成；所有模型（建筑套件/人形/沉船/灯塔）程序化建模；所有音频（海床/风/潮歌/脚步/铃/船螺）用 WebAudio 实时合成。仓库只有代码。
- **渲染**：ACES 色调映射、UnrealBloom、胶片颗粒、暗角、轻微色差、指数雾、PCF 软阴影、PBR 材质（法线贴图）、动态水面（顶点波 + 滚动法线 + Fresnel）。
- **AI**：状态机（劳作/巡逻/起疑/追击/搜索/归位），视锥 + 视线遮挡 + 听觉半径，噪音事件总线。
- **动画**：关节层级 + 程序化步态/劳作/歌唱姿态（无关键帧文件）。

## 项目结构

```
docs/            设计文档 + 美术圣经
src/
  core/          引擎壳(渲染/后处理)、输入、程序化音频
  world/         程序化贴图、材质、几何合批、地形与渔村大地图、水面、天空
  entities/      玩家控制器、程序化人形、潮尸AI、村犬、海鸟群
  systems/       视奸、潜行威胁聚合、叙事导演(文书/触发器/检查点/终局)
  ui/            HUD(字幕/目标/文书/暂停/死亡/结局)
scripts/         无头浏览器验证(构建→启动→截图→按20分钟节拍自动通关)
```

## 自动化验证

```bash
node scripts/verify.mjs smoke        # 渲染与移动冒烟测试
node scripts/verify.mjs looks        # 关键场景与角色外观 + FPS
node scripts/verify.mjs playthrough  # 全流程通关（视奸/谜题/血潮/灯塔/终局，逐节拍断言）
```

截图输出到 `verify/`。全流程脚本会断言每个主线 flag（`knowKeySpot`、`puzzleSolved`、`bloodTide`、`breakerOn`、`ended`……）并确认结局遮罩显示、全程零控制台报错。
