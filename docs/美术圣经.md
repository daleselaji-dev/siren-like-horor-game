# 《返潮》美术圣经

## 一、总基调

**「楼是干的，但它开始承受深海的时间。」**
不是哥特，不是废土，不是血浆。是 2001 年一个你亲戚可能在里面摆过酒的县镇大酒店——
红漆总台、水磨石、金不锈钢包边、红毯大楼梯——只是建材来自古海床，屋子记得海底。

**先真实后异常**：6 米外一切都是具体的 2001 年中国县镇；2 米内才允许读出唯一主异常。

**漠视感**：镇子不看你。构图上让主角永远处在「布告的边缘、名单的末行、镜头的余光」——
告示是贴给全镇的，广播是念给全镇的，你只是恰好也听见了。

## 二、色彩剧本

| 酒店室内 | 荧光灯白 `#eef2e8` / 钨丝暖 `#ffd9a0` / 灯箱奶白 | **禁止把渔村阴天光搬进室内**——室内光必须是灯具给的 |
| 核册红金 | 幕布红 `#8c1616` / 缎面枣红 `#6e1f1f` / 金 `#f0d28c` | 全图最高饱和度保留给仪式：红幕、「還」字金匾、红毯、「名」灯 |

## 三、材质语言

- **水磨石**：骨料颗粒 + 打蜡反光（roughness 0.35），大堂主地面；渗漏态浮出同心沉积纹。
- **矿棉吊顶**：0.6m T 型龙骨格 + 针孔肌理 + **板边水渍圈**（返潮从吊顶开始）。
- **红毯**：短绒噪波 + 压痕；既是视觉主轴也是玩法（吸振/减噪安全带）。
- **缎面（枣红袄/桌布）**：各向异性高光模拟，暗部沉、高光窄。
- **浮木（侍应颈臂）**：浪蚀沟槽沿肌理方向，灰褐脱色，端面年轮。
- **沉积截面（托盘餐食）**：地层分色带，禁止做成腐烂食物。
- **居民楼室内**：石灰墙掉皮见报纸衬底、水泥楼梯磨圆角、水磨石窗台、
  的确良床单、搪瓷缸——「刚离开人」的生活质感，不许做成废墟。
- **镇上材质**：渔船木/条石/白灰剥落/青瓦/盐霜全部继承并提高分辨率与法线细节。
- 贴图全部 Canvas 程序化：颜色+法线+粗糙度三件套；主视觉 1024²，小件 512²/256²。

## 四、建筑形制

- **南方大酒店**：2001 年县镇「面子工程」——瓷砖外立面、绿玻璃幕、门头灯箱字、雨棚、
  室内红漆木作+仿大理石+金不锈钢包边。禁止做成欧美酒店或现代极简。
  **阈限序列**：门斗→大堂→大楼梯→回廊→客房走廊→后勤→楼梯间——
  每段用灯光节奏与进深收窄制造「预先空间」的不安，不靠堆红色。
- **海洋馆**：售票厅+玻璃连廊+主展缸厅，蓝瓷砖与亚克力展缸，断电后只剩应急灯。
- **家属楼**：九十年代水产公司筒子楼，外廊+晾衣绳+水泥楼梯间；
  室内两开间：外间八仙桌+CRT，里间床+五斗橱。可进可逛，门口挂栋号漆牌。
- **照相馆**：门市（柜台+背景布+橱窗全家福）+暗房（红灯、显影盘、挂绳夹底片）。
- **镇区**：渔寮单层石砌、旧海祀燕尾脊、清末石灯塔、条石堤、方格盐田——全部保留。

## 五、角色剪影（工位异常各一条，不许堆料）

- **报数员**：深色西装白衬衫，站姿过于端正。异常：口部鱼籽状钙化封死；麦克风线没入舞台。
- **侍应**：白衬衫黑马甲黑领结，托盘永远端平。异常：颈与小臂是浪蚀浮木；匀速传送带步态。
- **理册婆**：枣红缎袄，绾髻。异常：额上矿物孔板第三眼；镜中比现实早一拍、倒退走。
- **回眸客**：普通宾客装。异常：半透明多重曝光，回头的动作有三层残影。非敌对指针。
- **浮客**：宾客群像（的确良衬衫/西裤/连衣裙）。异常：脚尖离地半寸，只在阴影里看得出。
- **上宾（主怪）**：**永不出全身**。房间尺度的旧船板/脚手架木重组前肢，板间无肉，
  节点箍包浆**黄铜环带**；板条留**铁钉排**与劈裂木刺（加急赶工的痕迹），
  前臂绑红白刻度**丈杆**；上臂垂三股湿麻绳，绳端挂红漆「界」字**界桩木牌**随动作轻摆；
  腕端半圆木掌+四根旋木尖指，会在地板上轻敲——是在数，不是在抓。从不吼叫，靠振动定位。
  它不是猎手，是丈量员——动作永远是「清点」而非「扑咬」。
  被镁光拍到时当场摆回**丈量姿态**（板条排直、绳牌垂稳）——像一张被显影的旧照片。
- **镇民/巡堤人/保卫**：还在履职的普通人，异常只挂三轴细节（钥匙串钙化、工装盐晕）。
- **周絮**：枣红缎袄，长直发。异常：盐霜附居痕迹沿一侧脸颊→眼角→额角**不对称蔓延**，
  夹带数粒藤壶状附居锥——只长一侧，6m 外读作胎记，2m 内读出它是活的。

人形建模规则：Lathe 躯干+雕刻球头+胶囊四肢+合并网格；**禁止裸 BoxGeometry 拼人**；
远景人群用烘焙合并网格（一桌一 draw call）。

人物近景铁律（反蜡人五件套）：
1. **皮肤双层法线**：底法线烘皱纹/斑驳，清漆层第二法线平铺细胞噪声毛孔——
   高光必须「走」在毛孔上碎掉，整片亮起来的是蜡。
2. **菲涅尔皮脂层**：清漆按人群分级——失血员工湿(0.5)、常人微油(0.3)、老年干(0.16)、
   理骨员近无(0.05)；油区在粗糙度图里成片，不均匀。
3. **眉睫是毛不是几何**：alpha 贴片逐根画，内浓外疏；嘴唇是体积（双唇峰+唇珠+口裂缝），
   唇是脸上最湿的一块。
4. **脸必须一直在微动**：错拍眨眼、眼球弹道扫视+注视微漂、单侧嘴角抽动、单侧挑眉；
   **酒店员工全部冻结**——「不动」只有在别人都在动时才吓人。
5. **近距 LOD**：2m 内换高段数头模（皮下微起伏）+加密毛孔法线；6m 外先读成「具体的人」。

## 六、光与雾

- 镇上：冷白平行光（阴天漫射）+ 灯笼橘点光；指数雾 60–90m。
- **酒店室内**：荧光灯管（含坏镇流器频闪）、钨丝吊灯、门头灯箱、CRT 荧光——
  每盏灯有灯具网格+发光面；吊顶用微量自发光近似反弹光。
- **居民楼室内**：一户一盏白炽灯（人走灯不灭——告示要求的），楼道声控灯只在你出声时亮。
- 灯光预算：同屏点光 ≤16（低配 10），按相机距离轮换；室内灯挂「进楼才点亮」开关。
- 渗漏态：雾压到 35m、色温向深绿黑走，「名」灯由红转青，红金在其中更刺眼。

## 七、后处理

ACES 色调映射 → Bloom（阈值高，只让灯箱/灯笼/CRT 溢光）→ 暗角 → 胶片颗粒 →
轻色差（视奸/濒死加重）。视奸滤镜按工位区分（报数员俯瞰/浮客上浮/回眸客残影）。
相机闪光：一帧过曝白 + 随后两秒的负片残像渐隐（玩家也要付出「看不见」的代价）。

## 八、禁止事项（红线）

- 禁止蓝滤镜、触手主视觉、Gore 断肢、黑袍邪教、VHS glitch 滤镜。
- 禁止 jump scare 贴脸；恐惧靠「注意到不对劲」与「电视先播」。
- 禁止编号代号出现在玩家可见层；实体一律用核册工位名。
- 禁止骷髅/蜘蛛网/哥特烛台等欧美符号；禁止彩色霓虹赛博元素。
- 禁止丑化真实民间信仰；「核册还地」「借地三年」为虚构旧俗，不对应任何真实仪轨。
- **禁止婚俗口号与「上头」等旧线用语**——所有仪式文本一律用「核册/验户/照影/还地」体系，
  语气渗人、克制、公事公办：最吓人的话要写得像一张盖了章的通知。
