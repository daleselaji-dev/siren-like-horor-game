# 《咸潮》美术圣经

## 一、总基调

**"被潮水保存成标本的日常。"**
不是哥特，不是废土，不是血浆。是一个你外婆可能住过的渔村，只是所有东西都湿了三年，没有干过。

## 二、色彩剧本

| 阶段 | 主色 | 说明 |
|---|---|---|
| 前中期（永涨潮的白昼） | 青灰 `#5c6b73` / 铅蓝 `#3a4a56` | 阴天海边的冷光，天空永远像要下雨。太阳是一块隔着湿布的白斑。 |
| 暖点缀 | 灯笼橘 `#ff7733` / 香烛红 `#cc3311` | 全图唯一的暖色来自灯笼、香烛、炭盆——它们三年没有熄灭，是"不对劲"的暖。 |
| 血潮之后 | 暗红 `#4a1512` 水体 / 绛紫天 `#2a1a28` | 水面转暗红，天光压低，雾变咸腥的粉灰。 |
| 盐霜 | 灰白 `#c9c4b8` | 所有低处的墙根、船板、衣摆结着盐霜，高度一致（= 潮汐线），是全图最重要的视觉语言。 |

**规则：饱和度全局压低（≤40%），只有火光和血潮允许高饱和。**

## 三、材质语言

- **木**：深褐渔船木 + 灰绿苔痕 + 盐霜白边。板缝清晰（法线图强化）。
- **石**：花岗石堤条石，湿面反光（roughness 0.35），干面 0.85。
- **墙**：白灰抹面剥落露出夯土/砖，潮汐线以下整体泛盐白。
- **瓦**：闽东青瓦弧面 + 压瓦石。屋脊两端微微起翘，禁止北方官式大吻兽。
- **网**：晾在架上的渔网是重要剪影道具，半透明。
- **水**：不透明暗绿→血潮暗红；表面滚动双层法线，岸边白沫线 + 离岸二道碎浪白；
  月光在西南海面拖出一条**碎波带**（与天空月位对齐），血潮后整条道翻成暗红的"鳞"。
- **尸皮（v1.1）**：clearcoat 湿膜（水膜反光）+ sheen 尸蜡感 + 藤壶环带 + 皮下淤青；
  静脉纹/盐痂在颜色、法线、粗糙度、AO 四个通道同时表达。
- **AO 规则（v1.1）**：所有材质带凹腔 AO——缝隙、刻痕、剥落边缘要"藏得住脏"，
  由高度场双尺度推导，禁手绘死黑。

## 四、建筑形制（中式沿海，禁欧美）

- 渔寮：单层石砌 + 木门板 + 瓦顶压石。
- 祠堂/潮母宫：三开间、燕尾脊（弧线，非直角）、门前一对石炉、殿内梁上挂船模（沿海庙宇习俗）。
- 灯塔：清末样式石塔身 + 铁艺灯室。
- 石堤：条石斜坡 + 系缆桩。
- 晒盐场：方格盐田 + 木耙 + 盐堆。
- 沉船：木质渔船龙骨朝天，肋骨如鲸骨。
- **生活痕迹（v1.1）**：木桶/陶缸/竹篓/板凳/柴堆/缆绳圈/橹/咸鱼架/蟹笼——每件家什停在
  三年前被放下的位置；地面积水洼反灯火；80 年代木电线杆拉着垂线；三根烟囱冒着没人做饭的炊烟；
  村外坡上一片坟茔（旧坟歪碑、新坟无字、一个挖开却空着的坑）。

## 五、角色剪影

- **潮尸（村民）**：微驼、头略垂、双臂比常人下沉——"身体记得劳作"。衣着为 80 年代渔民便装（深蓝/灰卦衫、卷裤脚、赤足或胶鞋）。皮肤青白泛盐霜，**眼窝处一点冷光**（唯一的超自然发光点）。喉部微微鼓起（灌满海水）。
- **巡游型**：手提纸灯笼，灯笼即视锥。
- **歌唱者（小满）**：唯一直立挺拔的身影，红衣（全图唯一的整片红色布料），面向海。永远不跑。
- **潮母（终局剪影）**：不给清晰形体。海平线上山一样的暗影 + 成串灯笼光点 = 它的鳞。看不清才可怕。

## 六、光与雾

- 主光：冷白平行光（阴天漫射感，阴影软）。
- 雾：指数雾常开，能见度约 60–90 m；血潮后压到 35 m 且泛红。
- 灯笼/香烛：橘红点光 + bloom，是玩家的路标也是敌人的位置提示。
- 视奸滤镜：信号噪点、扫描线、边缘暗角、轻微色差。

## 七、后处理

ACES 色调映射 → Bloom（阈值高，只让火光和眼点溢光）→ 暗角 → 胶片颗粒（夜间加重）→ 轻色差（视奸/受伤时加重）
→ **片门抖动**（24 格/秒亚像素画框浮动——"被潮水腌过的胶片"连画框都没坐稳）
→ **镜头水痕**（血潮/溺水时几列水顺着镜片往下爬，带折射与一线高光）。

## 八、禁止事项

- 禁止跳脸 Jump-scare 贴脸怪；恐惧靠"注意到不对劲"。
- 禁止骷髅、蜘蛛网、哥特烛台等欧美恐怖符号。
- 禁止直接使用真实妈祖/龙王名号与形象（一律用虚构"潮母娘娘/咸神"），不得丑化真实民间信仰。
- 禁止彩色霓虹、赛博元素。
- 禁止裸露血腥断肢；血潮是"水的颜色不对"，不是血浆飞溅。
