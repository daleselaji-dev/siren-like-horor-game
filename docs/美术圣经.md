# 《返潮》美术圣经（本仓库 M01 实施版）

> 依据 ART_DIRECTION_CANON_vNEXT 与 F01_HERO_MONSTER_CANON 落地到程序化管线。
> 总纲：**先真实，再异常。** 恐怖来自「一栋你认识的楼不对劲了」，不来自怪物贴脸。

## 一、总体基调

- 年代锚点：**2000 年前后的中国沿海小城**。千禧婚宴酒店 = 上一个时代最后的体面。
- 情绪：潮、旧、没有下文。所有东西都保养着，但都过期了。
- 灯光哲学：**亮着一半**。千禧水晶灯只剩内圈亮；日光灯有一根接触不良；
  婚宴厅只剩暗红余光。黑暗不是没有灯，是灯到点了没人开。

## 四、场景语汇（M01 迎宾楼）

- **前庭**：湿沥青倒影、干喷泉（池底褪色的囍）、灯箱招牌「迎宾楼」缺笔画地闪
  （镇流器老化的明灭，不是恐怖游戏式频闪）、拆迁公告、海雾从海那边漫进来。
- **大堂**：抛光砖残余镜面反射、红地毯引导线、千禧水晶吊灯（亮一半）、
  前台（登记簿摊开）、婚纱照易拉宝、墙钟（比监控慢十八秒）、内湾工程剪报框。
- **保卫室**：行军床、2003 挂历、热水壶、三块 CRT 监控屏（RTT 实时画面）、冷绿日光灯。
- **客房走廊**：Depth 异常主体。基础段 3 盏日光灯 + 5 间客房门 + 尽头风景画（桥是修好的）；
  Leak 后延伸段灯距变大、门牌无数字、尽头一面镜子。地毯纹是拉长的回形纹。
- **婚宴厅**：四十桌红台布（Demo 内 8 桌 + 舞台），转盘、摞碗、折口布、双囍红绒幕、
  两盏只剩余光的吊灯、舞台红洗光、电视车 + 录像机。
- **后厨**：不锈钢案台冷反光、挂钩、冰柜（贴进货单）、排班表、一根接触不良的日光灯。
- **海**：出现在前庭视野尽头。比记忆里近。远海无声闪电，数秒后才有闷雷。

## 五、人物（程序化雕塑规格）

### 通用人体（humanoid.js v3）

- 头：高分段球体 + **高斯特征场顶点位移**——眉弓/眼窝/鼻梁/颧骨/法令区/下颌线/下巴，
  外加耳廓（独立雕刻件）。参数化（眉弓厚度/眼窝深度/颊凹/年龄下垂）以区分个体。
- 躯干：Lathe 侧影 + 肩斜方肌隆起 + 肋弓起伏 + 中年小腹微凸；锁骨为独立雕刻件。
- 四肢：变径胶囊（肘/膝/踝有骨点收放）；手 = 掌 + 分指节手指（指节分明）。
- 动画原则：**相位滞后**（头与躯干晚于骨盆半拍）；步态按种子做个体差异；
  劳作动画（拖地/切配/擦拭/写字）优先于"站桩"。

### F01「井身者」王承海

- **远读（6m）**：可信的中年维修工。灰蓝工装外套（领缘暗红）、泛黄衬衫、
  深色化纤裤、旧皮鞋、**侧分短发（带油光）**。站姿疲惫但端正——他在上班。
- **近读（2m）**：
  - 头部在眼位/口位**删除面片开真孔**（不是贴图）；
  - 每孔内接一口井：BackSide 反锥井壁（**口窄腹宽**——几何上里面比外面大）
    + 递进环圈（砌层间距越深越大，打乱透视）+ 吸光井底 + **井底水光**
    （2m 内可辨、缓慢晃动，警戒时变亮）；
  - 面部其余部分保持人类解剖：更深的眼窝、压重的眉弓、颊凹、年龄下垂。
- 材质：皮肤程序化贴图带静脉/色斑/湿感（高 envMapIntensity 低粗糙度区分 T 区）；
  工装布纹三件套（颜色/法线/粗糙度）表达洗旧的化纤。

## 六、渲染与后处理

- ACES 色调映射 + UnrealBloom（阈值高，只有灯芯泛光）+ 胶片颗粒 + 暗角 + 轻微色差。
- 分离调色：高光提烟黄、阴影压灰绿。
- 雾分级：室外海雾浓（指数雾 + 贴地雾片向楼漂移）/ 室内潮气薄；
  **压力锋面**（Depth 泄漏时）雾变密变冷、全局光压低——灰绿方向。
- RTT 监控画面：320×240 独立机位渲染到宴会厅电视 + 保卫室三屏，冷绿调。
- 听潮后处理：桶形畸变 + 呼吸脉动 + 色偏/去饱和按载体区分；**无噪点无扫描线**。
- 灯具行为：镇流器老化明灭（低频随机 + 二次谐波），不做高频 horror 频闪。
