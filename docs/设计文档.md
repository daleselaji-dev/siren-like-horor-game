# 《返潮》(FANCHAO) 设计文档

> 中式民俗海洋恐怖 · 《死魂曲》(Siren) 骨架 × 《返潮》三轴 · 第一人称潜行 Demo
> 平台：浏览器 WebGL (Three.js) / Electron 桌面版 · 时长目标：约 20–35 分钟

---

## 一、世界观

### 1.1 背景

2001 年秋，中国东南沿海县镇 **蚀湾**。九十年代填湾造地，湾底的古海床被挖起来做了建材——
镇南由此立起两座「面子工程」：**南方大酒店**（三层，红漆总台、水磨石大堂、红毯大楼梯）
与 **蚀湾海洋馆**（酒店东侧连廊相接）。楼是新的，骨头是老的：墙里的砂石在海底躺了几万年。

**返潮**：潮来了，但水没有来——来的是**深度**。建筑是干的，却开始承受深海的时间：
吊顶板边缘洇出盐晕，木地板像船舱一样呻吟，水磨石地面浮出沉积层的同心纹。
返潮不淹人，它只是让屋子里的每一件东西想起自己来自海底。

**喜事**：镇上望族周家嫁女，全镇在南方大酒店办宴。这同时是一场旧俗——**许潮**：
把新娘许给海，换五十年潮平。宾客不是邪教徒，他们是真心来吃喜酒的普通人；
他们只是同时也真心相信，这门亲事本来就该办。

### 1.2 主角

你是新娘 **周絮** 的闺蜜，今晚的**伴娘**。渡船在滩涂搁浅，你比婚宴迟到了半天。
旧俗里有一条你不知道的细则，录像带里才说：**若海不满意新娘，就收影子——伴娘替嫁。**
你从进镇那一刻起，就已经在名单上了。

### 1.3 恐怖三轴

1. **CRT 预现**：镇里和酒店里的 CRT 电视/监视器不播现在——播**这个空间的下一个稳定形态**。
   电视先播，现实兑现。看屏幕是最好的侦察，也是最坏的消息。
2. **残骸四证据**：深压蠕变（木材像在深海被压过）、附居寄生（墙面藤壶状钙化）、
   沉积时间（托盘/餐食呈地层截面）、空间耐压（走廊断面呈圆弧、门洞加厚）。
   异常不靠血浆，靠「材质学不对劲」。
3. **喜事议程时钟**：司仪广播推进全镇状态——
   **迎宾 → 入席 → 上菜 → 敬酒（返潮点火）→ 上头 → 送入洞房**。
   每次切换前全镇**收声两拍**再出广播。议程可拖延（破像），不可取消。

## 二、核心机制

### 2.1 操作

| 键位 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标 | 视角（指针锁定） |
| Shift（按住） | 潜行（蹲低，减速，降噪，减振） |
| E | 互动（文书 / 推门 / 合闸 / 播带 / 破像） |
| Q 或 Tab | 视奸（切入/切出附近载体视野；切入后再按换目标） |
| Esc | 暂停菜单 |

### 2.2 视奸（Sightjacking）

- 静立按 Q 进入「听潮」：噪点扫台切入附近载体（镇民、侍应、保卫、司仪、浮客、回眸客）。
- 每种载体有专属滤镜：司仪的眼睛俯瞰全宴会厅（他不动，是侦察位）；浮客视野轻微上浮摇晃；
  回眸客视野是多重曝光残影。
- 两处主线必须靠视奸推进：堤门钥匙（借巡堤人的眼）与宴会厅布局侦察（借司仪的眼）。
- 视奸时本体原地失明，有风险。

### 2.3 宴席工位（实体不可杀，抓住 = 引座）

| 工位 | 常态 | 异常（2 米内可读） | 威胁模型 |
|---|---|---|---|
| **司仪** | 舞台上主持议程，声音先于手势 | 口部鱼籽状钙化封死——广播不是从嘴里出来的；麦克风线没入舞台 | 不追人；他的眼睛是全厅视奸侦察位 |
| **侍应** | 匀速传送带步态巡菜 | 浪蚀浮木质感的颈与小臂；托盘上的菜是沉积岩截面 | 视觉+听觉巡逻；抓住玩家＝**引座**回宴席空椅 |
| **全福婆** | 上头仪式主持 | 额上第三只眼是矿物孔板；**镜中的她比现实早一拍**，且倒退着走 | 追逐段落 Boss；只能借三面镜提前一拍躲 |
| **回眸客** | 站在人群里，忽然回头看你 | 半透明多重曝光残影 | 非敌对；残影指向下一个线索 |
| **浮客** | 宴会厅/大堂的宾客群 | 脚尖离地半寸；敬酒后集体起立 | 环境压迫，不追击 |
| **上宾** | 空椅上的「那一位」 | 房间尺度的木板重组前肢，板间无肉，从不出全身，**从不吼叫** | 靠**振动**感知：红毯上潜行可过，硬地跑动即被点名 |
| 镇民/巡堤人/保卫 | 还在履职的普通人 | 挂三轴细节（工装盐晕、钥匙串钙化） | 常规三段警戒潜行 |

- 全部实体**不可被杀死**。被抓住＝「引座」演出（被架回宴席空椅，桌牌写着你的名字）→ 回检查点。

### 2.4 潜行模型

- 可见度 = 视锥 × 距离 × 姿态 × 遮挡（射线，含楼层判定）× 环境光。
- 噪音 = 速度 × 地面材质（瓷砖/水磨石传远 > 木板 > 沙土 > **红毯减噪**）。
- **振动**（上宾段落专用）：硬质地面移动积累振动条，红毯吸振；振动满 → 上宾点名。
- 警戒三段：怀疑（?）→ 确认（!）→ 追踪；丢失后绕最后目击点搜索，再归位。

### 2.5 CRT 预现与破像

- 场景内真实 CRT（服务走廊、保卫科九宫格、807 电视）用 RenderTarget + 第二相机渲染
  该空间的「下一态」：预现层里比现实**多**的东西即将出现，**少**的东西即将消失。
- **破像**：对预现画面中的关键结构（配电柜、囍匾）动手，使现实与录像不符 →
  该次预现作废，议程被拖延一拍。保卫科教学 1 次 + 终局 1 次。
- 玩家被「点名」（屏幕上出现你坐在空椅上）后，破像是唯一解。

## 三、世界结构（连续大地图：镇口进镇动线 + 蚀湾小镇 + 南方大酒店多层室内）

```
[长途车站/镇口牌坊]  ← 玩家出生（2001 夜班车到站，末班车掉头回县城）
        ↓ 栅门落闩（视奸岗亭员 → 小窗拨闩）
[镇前街 · 杂货铺/通宵录像厅/磁卡电话亭/政府告示墙]  ← 怀旧恐怖 + 规则告示（规则一/二）
        ↓ 街灯主干道
[十字街心 · 公告栏/广播站/市场/晒盐场]
   ↙            ↓             ↘
[家属区旧宿舍] [南方大酒店]  [海洋馆连廊→主展厅]
   ↓             ↓             ↓
[堤门→石堤/渔寮/滩涂] [宴会/客房] [巨物残骸+处理间]
        ↘            ↓         ↙
            [灯塔 / 沉船湾 · 终局]
```

- **镇口**：长途车站（雨棚荧光管/班次牌「末班 21:30 已发」/长椅行李箱=文书①）、
  末班车离站演出、蚀湾石牌坊+木栅门（夜里落闩，闩在里侧）、岗亭（岗亭员整夜盯着闩杆——
  视奸教学位）、木栅围栏、政府告示墙（文书②·夜间三则=规则怪谈教学）。
- **镇前街**：沥青县道（路基整平）、水泥杆街灯、杂货铺（半落卷帘）、**通宵录像厅**
  （雪花大屏、无人长椅——阈限空间）、绿皮磁卡电话亭（路过时它响，接起是劝你回去的女声）、
  十字街心木路牌（五向箭头）。
- **家属区**：水产公司三层筒子楼，外廊晾衣、只有一扇亮窗——灯后头没有人影。
- **堤门反向**：堤门的闩在镇这侧——滩涂/渔寮/石堤成为进镇后的支线（渔民日记）。
- 小镇外景（滩涂、石堤、渔寮、晒盐场、灯塔、潮母宫）继承《咸潮》地形骨架并全面提升。

**南方大酒店**（2001 年县镇酒店形制）：
- **1F 大堂**：红漆总台+登记簿、水磨石地面、金不锈钢包边镜面柱、红毯大楼梯、塑料绿植、吊灯、壁画。
- **1F 宴会厅**：红金囍、六张圆桌+方凳、舞台红幕金匾、立式麦克风、**上宾空席独桌**、藻井灯箱、串灯笼。
- **1F 服务走廊**：传菜口、备餐台、CRT 监视器（预现教学）、员工须知（文书⑤=规则三）、配电间。
- **2F 回廊**：俯瞰大堂；**保卫科**监控室（九宫格 CRT 墙，破像教学）。
- **3F 客房走廊**：客房门牌（含 107）；**807 套房**（三楼尽头挂八楼门牌——错一层的走廊）。
- **海洋馆**（东连廊+售票厅+**主展厅**+处理间）：
  - **主展厅·巨物残骸**：干涸主展缸缸底的沉积床上，12 节椎弓 + 六对房间尺度肋拱 +
    空眼眶头骨；三根吊索从屋面绷着脊柱；标本牌只写「未定种·一九九八填湾工地出土」。
    干燥、无蓝滤镜、无触手——只有骨头和它不该有的体量。理骨员绕台座巡夜（侦察/绕行段落）。
  - **处理间**：钢桌骨件、胶皮围裙、母带铁柜（文书⑧）。

| 节拍 | 地点 | 内容 |
|---|---|---|
| 1 夜班车到站 | 长途车站 | 电影运镜开场（末班车掉头离站）；长椅行李箱（文书①喜帖） |

| 2b 街心 | 镇中心 | 公告栏（文书③婚宴通知）+ 广播站（文书④值班记录）；周期性**镇广播报时**开始考验规则一 |
| 2c 堤门支线 | 堤门→渔寮 | 堤门从镇侧拨闩，滩涂/渔寮开放（文书⑩渔民日记，可选） |
| 3 赴宴 | 酒店 1F→3F | 大堂满员；登记簿（文书⑥）；上 807 陪新娘**上头**，拿到**手镜** |

| 5 敬酒=返潮点火 | 全楼 | 议程推进到「敬酒」→ 全楼切**渗漏态**：浮客化、海色深绿黑、空盘侍应开始执行规则三 |
| 6 点名与破像 | 2F 保卫科 | 值班日志（文书⑦）；钥匙柜=CRT **点名**，规则二 75 秒倒计时起走 → 一楼配电间拉总闸**破像** |
| 7 母带 | 大堂→巨物厅 | 大堂**上宾振动潜行**；主展厅**巨物残骸**侦察绕行（理骨员巡逻，围索限定外圈）；处理间铁柜取**母带**（文书⑧巡检单） |
| 8 上头·追逐·终局 | 807→宴会厅→灯塔 | 807 播母带（影子规则揭示，文书⑨）→ **全福婆追逐** → 宴会厅**大破像**（扯囍匾）→ 海雾散，走高堤到灯塔结算 |

失败态：被引座 → 检查点重试（每区入口 + 关键事件后自动存档）。
坏结局暗示：宴席空椅的桌牌，在预现画面里换成了你的名字。

### 规则怪谈（可玩规则 ×3：告示教学 → 违反有罚 → 遵守可绕）

| 规则 | 教学 | 违反 | 遵守 |
|---|---|---|---|
| 一 · 广播报时期间勿面向海 | 告示墙第一条 | 凝视海向 2 秒：视线被海接走（强制视奸）→ 引座回检查点 | 背海而立念完广播，无事 |
| 二 · 电视映出本人须当即断电/离开 | 告示墙第二条（手写补注：破像要快） | CRT 点名后 75 秒倒计时（30/12 秒两次警告）耗尽 → 「录像播完」引座 | 时限内拉总闸破像，点名作废 |
| 三 · 空盘侍应面前收手 | 员工须知（文书⑤） | 渗漏态后被起疑的空盘侍应看到站立亮手 → 立即警觉引座 | 蹲下收手，疑心消退，侍应从面前过去 |

## 六、技术选型

**Three.js (WebGL2) + Vite + 原生 WebAudio + Electron，零二进制资产（全程序化生成）。**

### 6.1 代码结构

```
src/
  main.js              入口 / 主循环 / 实体编制 / 灯光预算
  core/engine.js       渲染器、后处理链、resize
  core/input.js        键鼠 + 指针锁定
  core/audio.js        WebAudio 合成（海床/喜歌AB/司仪广播/收声/脚步/木呻吟/电话/CRT）
  world/textures.js    Canvas 程序化贴图 + 法线/粗糙度（水磨石/吊顶/墙纸/缎面/浮木/沉积）
  world/materials.js   材质库
  world/water.js       水面着色器（渗漏态深绿黑切换）
  world/town.js        蚀湾小镇大地图 + 碰撞 + 巡逻路点（继承咸潮地形骨架）
  world/hotel.js       南方大酒店三层室内 + 海洋馆（楼板/楼梯/房间/家具/灯位/地面材质区）
  world/sky.js         天空穹顶/雾/云/月
  entities/humanoid.js 高保真程序化人形（Lathe 躯干/雕刻头部/工位异常/烘焙人群）
  entities/enemy.js    工位 AI 状态机 + 浮客/回眸客/上宾
  entities/player.js   第一人称控制器（地面材质脚步）
  systems/sightjack.js 视奸（工位专属滤镜）
  systems/stealth.js   可见度/噪音/振动模型
  systems/crt.js       CRT 预现（RenderTarget+第二相机+破像）
  systems/agenda.js    喜事议程时钟（收声→广播→状态推进）
  systems/story.js     八节拍/触发器/检查点/文书/全福婆追逐/终局
  ui/hud.js            字幕/目标/文书/议程指示/振动计量/暂停
```

### 6.2 性能预算

- 目标 60fps（720p 集显 30fps）；静态网格按材质合批；宴会厅人群烘焙为合并网格；
- **灯光预算**：全图点光按相机距离排序，同屏只开最近 16 盏（低配 10 盏），其余熄灭；
- 阴影仅主平行光；CRT 预现 RenderTarget 低分辨率轮询刷新（每帧最多 1 块屏）。
