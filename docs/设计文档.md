# 《返潮》(FANCHAO) 设计文档

> 中式民俗海洋恐怖 · 《死魂曲》(Siren) 式潜行侦察 × 《寂静岭》式世界异化 · 第一人称潜行 Demo
> 平台：浏览器 WebGL (Three.js) / Electron 桌面版 · 时长目标：约 20–35 分钟

---

## 一、世界观

### 1.1 背景：借地三年

2001 年秋，中国东南沿海县镇 **蚀湾**。一九九八年填湾造地，湾底的古海床被挖起来做了建材——
镇南由此立起两座「面子工程」：**南方大酒店**（三层，红漆总台、水磨石大堂、红毯大楼梯）
与 **蚀湾海洋馆**（酒店东侧连廊相接）。楼是新的，骨头是老的：墙里的砂石在海底躺了几万年。

填湾那年，镇里的老人按旧俗跟海立了约：**借地三年**。字据烧给了海，条款只有老人知道。
三年到了。今夜是**核册还地**之夜——全镇到南方大酒店吃最后一顿「还地饭」，
报数员逐户念名，念到的把手放在册上。核对无误，账就清了。
至于海收走的是什么，告示上没有写。

**返潮**：潮来了，但水没有来——来的是**深度**。建筑是干的，却开始承受深海的时间：
吊顶板边缘洇出盐晕，木地板像船舱一样呻吟，水磨石地面浮出沉积层的同心纹。
返潮不淹人，它只是让屋子里的每一件东西想起自己来自海底。

### 1.2 主角：外证

你是外乡人**阿澄**。周絮——你唯一在蚀湾的旧友——写信求你来做核册的「**外证**」：
名字不在镇册上的人，才有资格看着册子合上。末班长途车把你放在镇口，司机没熄火，
他等的不是你，是掉头。

镇上没有人迎你，也没有人拦你。他们看你的眼神，像看一件已经登记在册的物品。
旧俗里有一条没人告诉你，母带里才说：**册末留着一行空名。
海若不认这本册，就把镜中陪坐的收走——所以外证要挑外乡人。外乡人走了，镇上不用挂白。**
你从进镇那一刻起，就已经写在那行空名上了。

### 1.3 恐怖三轴

1. **CRT 预现**：镇里和酒店里的 CRT 电视/监视器不播现在——播**这个空间的下一个稳定形态**。
   电视先播，现实兑现。看屏幕是最好的侦察，也是最坏的消息。
2. **残骸四证据**：深压蠕变（木材像在深海被压过）、附居寄生（墙面藤壶状钙化）、
   沉积时间（托盘/餐食呈地层截面）、空间耐压（走廊断面呈圆弧、门洞加厚）。
   异常不靠血浆，靠「材质学不对劲」。
3. **核册议程时钟**：报数员广播推进全镇状态——
   **起雾 → 收港 → 归屋 → 验户（返潮点火）→ 熄灯 → 还地**。
   每次切换前全镇**收声两拍**再出广播。议程可拖延（破像），不可取消。

### 1.4 风格双轴：漠视 × 异化

- **《死魂曲》轴——诡异漠视**：镇民不是怪物，是「还在履职的普通人」。他们不看你，
  不与你说话；广播、告示、登记簿全部把你当作一个待核对的条目。恐怖来自
  「所有人都知道规则，只有你不知道」。
- **《寂静岭》轴——压迫异化**：验户之后世界切换到**渗漏态**（返潮异化）：
  雾压下来、人变少、席上的宾客脚尖离地、街上的灯换了颜色、走过的路不再是原来的路。
  不是换滤镜——地图、敌人、路线全部改变。

## 二、核心机制

### 2.1 操作

| 键位 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标 | 视角（指针锁定） |
| Shift（按住） | 潜行（蹲低，减速，降噪，减振） |
| E | 互动（文书 / 推门 / 合闸 / 播带 / 破像 / 拾取道具） |
| Q 或 Tab | 视奸（切入/切出附近载体视野；切入后再按换目标） |
| F | 镁光闪（海鸥牌相机） |
| G | 投放发条闹钟 |
| V | 倒贝灰线 |
| R | 录音对照（手提录音机回放磁带） |

| Esc | 暂停菜单 |

### 2.2 视奸（Sightjacking）

- 静立按 Q 进入「听潮」：噪点扫台切入附近载体（镇民、侍应、保卫、报数员、浮客、回眸客）。
- 每种载体有专属滤镜：报数员的眼睛俯瞰全宴会厅（他不动，是侦察位）；浮客视野轻微上浮摇晃；
  回眸客视野是多重曝光残影。
- 两处主线必须靠视奸推进：镇口栅门门闩（借岗亭员的眼）与宴会厅布局侦察（借报数员的眼）。
- 视奸时本体原地失明，有风险。

### 2.3 反击与成长（有限资源，不是枪战）

实体不可杀，但可以**驱离、诱开、阻断**。三件工具全部符合「返潮怕干、怕定影」的设定逻辑：

| 工具 | 获取 | 用法 | 设定逻辑 |
|---|---|---|---|
| **海鸥牌相机（镁光闪）** | 镇前街**大新照相馆**柜台皮套；镁光泡补给在暗房/筒子楼五斗橱 | F 键闪光：看见光的实体被「定影」——捂眼僵直数秒并**放弃追击**；对上宾迫使其摆回丈量姿态定格 | 被拍下来的东西必须先跟照片对齐——闪光把它钉回上一个稳定形态 |
| **发条闹钟** | 家属楼 104 户饭桌 / 保卫科行军床头 | G 键放置，上弦两秒半、响九秒，把听觉范围内的实体钓去绕钟筛查（追击中看不见你的人也会被拐走） | 核册之夜的规矩是收声——出声的东西必须被登记 |
| **贝灰线** | 海洋馆**处理间**（理骨员的贝灰袋） | V 键在脚前倒一道**界**，追击实体到界前站定不肯踩过；上宾的掌到界前悬停 | 理骨用的贝灰吸潮——返潮的东西过不了干燥的坎 |

两个箱庭侦探环（轮 11 追加，不动潜行主轴）：

| 系统 | 获取 | 玩法闭环 | 设定逻辑 |
|---|---|---|---|
| **录音对照** | 2F 棋牌室手提录音机（自带磁带一）；磁带二在录像厅还带箱、磁带三在海洋馆值班桌 | R 键平放只有底噪与标签提示；带到**录制地**回放，听出录音与眼前**对不上的那一处**（带里数九副碗、桌上只摆八副；104 应到的由 201 的嗓子替答；墙上第三条告示被人换过）→ 三个暗格奖励点亮 | 录音是「上一轮核册」的存档——对不上的地方就是被改过的地方 |
| **保险丝分闸** | 配电间总闸旁分闸板（大堂/西翼/客房层三路瓷底保险丝）；备品丝藏在备餐间纸箱 | E 开板后 1/2/3 拔插；拔下的保险丝揣走=「黑暗」成为可搬运的行装——断电堂口灯全灭，玩家在暗区所有敌人视程 ×0.6；代价是自己也只剩肉眼。后勤线/楼梯间走应急电不受板控 | 灯是核册的眼线——拔掉哪一路，哪一路就暂时「没人看」 |

成长线（RPG 探索感）：

- **镁光泡**：有限弹药（照相馆柜台皮套 2、暗房 2、筒子楼五斗橱 2、上宾席桌布下 2）——探索半径直接决定反击次数。
- **区域钥匙**：海洋馆钥匙（主线）；筒子楼可进户、照相馆暗房藏补给（支线）。
- **行装可见**：HUD 行装栏逐行点亮（镁光/闹钟/贝灰/录音带/保险丝）——捡到什么、还剩几发一眼可读。
- **异化态新路线**：渗漏态后主街被**沉积脊**封死，去酒店改走**床单巷**（湿床单挡视线不挡人，
  有掩护的潜行道）或**盐田西线**（绕远、空旷，且轮 12 后有湿客巡守）——地图知识本身就是成长。

### 2.4 核册工位（实体不可杀，抓住 = 引座）

| 工位 | 常态 | 异常（2 米内可读） | 威胁模型 |
|---|---|---|---|
| **报数员** | 舞台上念议程，声音先于手势 | 口部鱼籽状钙化封死——广播不是从嘴里出来的；麦克风线没入舞台 | 不追人；他的眼睛是全厅视奸侦察位 |
| **侍应** | 匀速传送带步态巡菜 | 浪蚀浮木质感的颈与小臂；托盘上的菜是沉积岩截面 | 视觉+听觉巡逻；抓住玩家＝**引座**回宴席空椅 |
| **理册婆** | 照影仪式主持 | 额上第三只眼是矿物孔板；**镜中的她比现实早一拍**，且倒退着走 | 追逐段落 Boss；只能借三面镜提前一拍躲 |
| **回眸客** | 站在人群里，忽然回头看你 | 半透明多重曝光残影 | 非敌对；残影指向下一个线索 |
| **浮客** | 宴会厅/大堂的宾客群 | 脚尖离地半寸；验户后集体起立 | 环境压迫，不追击；渗漏态后出现在街上 |
| **上宾（主压迫）** | 空椅上的「那一位」 | 见 2.5 | 靠**振动**感知：红毯上潜行可过，硬地跑动即被点名 |
| 镇民/巡堤人/保卫 | 还在履职的普通人 | 挂三轴细节（工装盐晕、钥匙串钙化） | 常规三段警戒潜行 |

- 全部实体**不可被杀死**。被抓住＝「引座」演出（被架回宴席空椅，桌牌写着你的名字）→ 回检查点。

### 2.5 主怪：上宾（丈量的东西）

> 「上宾　壹位　席设宴会厅正中　到时自来　毋须引路」——登记簿最后一栏

**设定**：海派来收地的**丈量员**。它不吃人、不吼叫、不奔跑——它**清点**。
它由填湾时沉入湾底的旧船板、脚手架木与量地的杆尺重组而成：房间尺度的木板前肢，
板间无肉。看得清的细节全在「加急赶工」上：板条上留着**铁钉排**与劈裂的木刺，
节点箍着包浆的**黄铜环带**，前臂绑一支红白刻度的**丈杆**；上臂垂三股湿麻绳，
绳端挂涂了红漆、写着「界」的**界桩木牌**，随动作轻摆。腕端是半圆木掌，
四根旋木尖指会在地板上轻轻**敲击**——不是在抓，是在数。
它走过的地方等于「量过了」——量过的东西就是海的。

**行为**：永不出全身（只出前肢与垂绳，主体始终在天花以上/景深之外）；
靠**振动**清点你的位置——硬地上的脚步是在向它报数。红毯吸振，是唯一的安全带。
被它合拢前肢抓住＝引座：你醒来时坐在空席上，桌牌写着「上宾」。

**反制**（三件工具全部对它生效，全部只能拖延，不能消灭）：
相机闪光迫使它与「上一张照片」对齐——当场摆回**丈量姿态**定格数秒（板条排直、绳牌垂稳）；
贝灰线它不跨——掌到界前**悬停**，不肯越界，只肯等；
闹钟能把那条手臂**钓离**你的地板（有声音的东西要先登记）。
你面对的不是一只怪物，是一次丈量。

### 2.6 潜行模型

- 可见度 = 视锥 × 距离 × 姿态 × 遮挡（射线，含楼层判定）× 环境光。
- 噪音 = 速度 × 地面材质（瓷砖/水磨石传远 > 木板 > 沙土 > **红毯减噪**）。
- **振动**（上宾段落专用）：硬质地面移动积累振动条，红毯吸振；振动满 → 上宾点名。
- 警戒三段：怀疑（?）→ 确认（!）→ 追踪；丢失后绕最后目击点搜索，再归位。

### 2.7 CRT 预现与破像

- 场景内真实 CRT（服务走廊、保卫科九宫格、807 电视）用 RenderTarget + 第二相机渲染
  该空间的「下一态」：预现层里比现实**多**的东西即将出现，**少**的东西即将消失。
- **破像**：对预现画面中的关键结构（配电柜、「還」字金匾）动手，使现实与录像不符 →
  该次预现作废，议程被拖延一拍。保卫科教学 1 次 + 终局 1 次。
- 玩家被「点名」（屏幕上出现你坐在空椅上）后，破像是唯一解。

### 2.8 世界状态切换：薄雾 → 返潮异化（渗漏态）

**触发**：议程推进到「验户」（宴会厅节拍），全镇收声两拍后切换，不可逆。

| 维度 | 薄雾态（前半） | 渗漏态（后半） |
|---|---|---|
| 天空/海 | 铅蓝阴天、雾 60–90m | 墨青、深绿黑水体、雾压到 35m |
| **天上（幻潮面）** | —— | 牌坊以内的镇子上空 **11.5m 悬一层没有水的海面**：焦散光网双层错速缓流、潮息涨落；**鱼影**分三群绕圈、一条 13m 的大影子绕全镇一圈三分多钟；拴船缆绳从街面绷直向上，**玻璃浮子顶在潮面底下**；潮面漏下三根淡光柱（椅阵/CRT 冢/街心） |
| **材质（双态）** | 街面砖木瓦干燥常态 | 十种外场共享材质整批「**泡透**」：色沉偏冷、粗糙度减半（湿反光）、反射 ×1.8；认领过的街面留 26 块**镜面水洼** |
| 酒店 | 满员喧暖、荧光稳定 | 大堂清空、席上浮客脚尖离地、荧光频闪加剧、墙面长出沉积 |
| 小镇街道 | 镇民各司其职（补网/晒盐/挑担/巡堤/看祠），镇犬游荡 | **履职的人一个不剩**（都「核对无误」了；只有守祀人还跪着）；街心摆出**面海椅阵**（三十把椅子朝海，每把上一双叠好的鞋）；沉积脊脚下堆起 **CRT 冢**（九台电视屏幕朝镇，整夜放雪花）；街面爬满盐痂斑 |
| 地图 | 主街（镇心→酒店）畅通 | **沉积脊**从海底顶上来封死主街——泥壳分层、嵌着别人家的门与半条舢板（碰撞体真实封路，不可翻越） |
| 路线 | 直走主街即达酒店 | 两条绕行：**床单巷**（东线，三道晾衣线挂满湿床单——挡视线不挡人，钻缝可过=有掩护的潜行道）或**盐田西线**（绕远、空旷，有湿客巡守） |
| 敌人 | 侍应慢巡、保卫未上岗 | 侍应加速+空盘规则生效、保卫上岗、上宾入场、理册婆待命；街上换成**湿客五员**巡走（主街床单缝/西环/湾岸/家属楼院/盐田道——衣服是镇民的，皮是泡过的；**不认贝灰界、镁光定身减半、耳朵灌水反而好骗**，闹钟是对它最有效的反制） |
| 声音 | 点名谣 A 面、市声 | 点名谣变调（泛音失谐）、广播语调下压、木结构呻吟、深海轰鸣一记 |

### 3.1 箱庭①：镇街区（含可进居民楼）

- **镇口**：长途车站（雨棚荧光管/班次牌「末班 21:30 已发」/长椅行李箱=文书①）、
  末班车离站演出、蚀湾石牌坊+木栅门（夜里落闩，闩在里侧）、岗亭（岗亭员整夜盯着闩杆——
  视奸教学位）、木栅围栏、政府告示墙（文书⑨·夜间三则=规则怪谈教学）。

### 3.2 箱庭②：南方大酒店（阈限空间序列）

按真实县镇酒店的空间序列布置「预先空间」——每一段都在为下一段做铺垫，
平常的空间靠**灯光节奏、进深压缩、镜面**制造不安，不靠堆红色：

1. **门斗**（双道玻璃门+风雨毯）：外冷内暖的过渡舱——门外听得见海，门内只剩点名谣。
2. **大堂**（挑高+水磨石+镜面柱）：满员却低声；总台登记簿；红毯从门口铺到大楼梯。
3. **大楼梯与回廊**（2F 井口俯瞰）：从公共到私密的第一道收窄。
4. **客房走廊**（3F）：等距门牌节奏——尽头 807 挂着八楼的门牌（错层的走廊）。
5. **后勤反面**（服务走廊/厨房/配电间）：瓷砖亮、管线裸露、CRT 推车——酒店的「后台」。
6. **楼梯间**（应急荧光+水泥台阶）：连接三层的垂直阈限——渗漏态后的主要动线。

- **1F 宴会厅**：红金主色、六张圆桌+方凳、舞台红幕+「還」字金匾、立式麦克风、
  **上宾空席独桌**、藻井灯箱、串灯笼。
- **海洋馆**（东连廊+售票厅+**主展厅**+处理间）：
  - **主展厅·巨物残骸**：干涸主展缸缸底的沉积床上，12 节椎弓 + 六对房间尺度肋拱 +
    空眼眶头骨；三根吊索从屋面绷着脊柱；标本牌只写「未定种·一九九八填湾工地出土」。
    干燥、无蓝滤镜、无触手——只有骨头和它不该有的体量。理骨员绕台座巡夜。
  - **处理间**：钢桌骨件、胶皮围裙、母带铁柜（文书⑦）。

## 六、技术选型

**Three.js (WebGL2) + Vite + 原生 WebAudio + Electron，零二进制资产（全程序化生成）。**

### 6.2 性能预算

- 目标 60fps（720p 集显 30fps）；静态网格按材质合批；宴会厅人群烘焙为合并网格；
- **灯光预算**：全图点光按相机距离排序，同屏只开最近 16 盏（低配 10 盏），其余熄灭；
- 阴影仅主平行光；CRT 预现 RenderTarget 低分辨率轮询刷新（每帧最多 1 块屏）；
- 居民楼室内使用体量化家具+程序化贴图，室内点光挂「进楼才点亮」的开关预算。
