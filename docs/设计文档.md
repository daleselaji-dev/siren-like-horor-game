# 《咸潮》(SALT TIDE) 设计文档

> 中式民俗海洋恐怖 · 《死魂曲》(Siren) 精神续作式 Demo
> 平台：浏览器 WebGL (Three.js) · 时长目标：约 20 分钟

---

## 一、世界观

### 1.1 背景

1980 年代末，闽东外海孤岛渔村 **盐门村**。村子三面礁石，一面石堤，堤外是天后宫的变体 **潮母宫**——供奉的不是妈祖，而是更古老的虚构海祀神 **潮母娘娘**（亦称"咸神"）。传说潮母以歌声托举渔船，也以歌声收走溺者：*"潮母收人，先收喉咙。"*

每逢甲子年大祭，村里要行 **锁潮祭**：由海祀祭师焚祭文、点三炷倒香、沉一口"喉铃"入海，替全村向潮母"赎喉"——保一村人的声音不被海收走。

三年前的锁潮祭，祭师 **闫守潮** 私改了祭文。他溺死的女儿 **闫小满** 生前是村里唱潮歌最好的姑娘，闫守潮想借大祭把女儿的声音从海里"赎回来"。祭文倒念，倒香顺点，喉铃没有沉海——**祭祀失败**。

当夜起了 **永涨潮**：暗红色的潮水漫过潮汐线就不再退去。整个盐门村被盐腌住——村民溺而不死，喉咙里灌满海水，仍然日复一日补网、晒盐、巡堤、祭潮。他们成了 **潮尸**。外界的地图上，盐门村所在的海域被标为暗礁禁航区。时间在村里错位：香烛永远点着，收音机永远播着三年前的台风警报，晒盐场的盐永远晒不干。

### 1.2 主角

**陈潮生**，26 岁，县海洋站的观测员，盐门村人，三年前离村。他不断收到姐姐 **陈织晚**（村小学教师）寄来的信——邮戳日期全部是三年前的同一天。最后一封信里只有一句话：*"弟，不要回来。潮母在点名，点到陈家了。"*

他回来了。渡船在村外礁滩触礁，陈潮生独自被冲上岸。Demo 从这里开始。

### 1.3 主题

- 恐惧来自 **"熟悉的日常被潮水保存成标本"**：补网的手不会停，灶台的火不会灭，广播不会换台。
- 歌 / 频率是诅咒的媒介：潮歌、船螺、渔鼓、电台杂音，听得越清，离"成为他们"越近。
- 没有可以战胜的敌人，只有可以避开的邻居。

## 二、核心机制

### 2.1 操作

| 键位 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标 | 视角（指针锁定） |
| Shift（按住） | 潜行（蹲低，减速，降噪，缩小被视距离） |
| E | 互动（拾取文书 / 开门 / 点香 / 拉闸） |
| Q 或 Tab | 视奸（切入/切出附近载体视野；切入后 Q/Tab 或 滚轮 换目标） |
| Esc | 暂停菜单 |

### 2.2 视奸（Sightjacking）

- 玩家静立时按 Q，进入"听潮"状态：画面变为信号噪点，按信号强弱扫到附近载体（潮尸、祭师、灯塔看守、村犬、海鸟群）。
- 切入后以载体第一人称视角实时观察：巡逻路线、钥匙位置、祭文顺序。
- 视奸时玩家本体 **原地不动且失明**，有风险；心跳声与视野边框噪点提示"你正在借别人的眼睛"。
- 强制视奸：结尾与歌唱者机制中，共鸣满格会被"拽入"视奸——这是崩溃death 演出的一部分。

### 2.3 潮尸行为（尸人精神）

| 类型 | 生前身份 | 常态 | 警戒 | 追踪 |
|---|---|---|---|---|
| 劳作型 | 补网人 / 晒盐工 | 原地循环劳作（补网、翻盐），偶尔直起身"望海" | 看到/听到玩家后僵住数秒、喉咙里发出灌水声 | 执着直线追踪，丢失目标后在最后目击点徘徊，再回到劳作，**永不忘记**（警戒半径永久+） |
| 巡游型 | 巡堤人 / 提灯祭仆 | 沿固定路线巡逻，提灯照明（灯即视锥可视化） | 同上，会呼喊引来附近潮尸 | 追踪时举灯狂奔，会翻越低障碍 |
| 歌唱者 | 闫小满（祭师之女） | 血潮后在村中游荡，不主动看，只唱 | 玩家进入歌声半径→"共鸣槽"上涨 | 共鸣满→强制视奸→溺毙。必须利用建筑遮蔽与间歇静默移动 |

- 潮尸 **不可被杀死**。没有武器。被抓住 = 溺毙演出（喉咙灌水声 + 屏幕漫红）→ 回检查点。

### 2.4 潜行模型

- 可见度 = 视锥角度 × 距离 × 姿态（潜行减半）× 遮挡（射线检测）× 环境光 × **芦苇隐蔽**。
- **芦苇隐蔽（v1.1）**：全图 20+ 处苇丛为软掩体。蹲入苇丛敌人有效视距缩到约 1/3
  （站立只吃 30% 效果——下半身遮着，上半身露着）；走动触发沙沙声提示但不产生听觉噪音事件；
  HUD 潜行指示切换为「苇 中」，字色染苇绿。巡逻线附近固定生成苇丛，保证机制必有可用场景。
- 噪音 = 移动速度 × 地面材质（水洼 > 石板 > 泥沙）。
- 警戒三段：怀疑（?，转头）→ 确认（!，僵直嘶吼）→ 追踪。
- **近身喉音（v1.1）**：常态劳作/巡逻的潮尸在 9 米内会周期性发出喉咙里的水声与气泡音——
  用声音描出"安全距离"的边，也让常态本身变得不对劲。
- **抓捕演出（v1.1 强化）**：确认抓住后进入 1.7 秒近身演出——两只泡胀的湿手从画面两侧
  滑入并收紧（挂相机空间的程序化手模），镜头被拽向对方的脸且带挣扎抖动，0.8 秒后喉咙进水
  （咕噜声 + 一串越冒越急的气泡），随后溺毙回检查点。

## 三、关卡结构（一张连续大地图，5 区互通）

```
        [灯塔·沉船湾]───(高堤,血潮后开放)
              │
   [潮母宫]──[村中心·晒盐场·广播站]
              │                │
        [石堤·渔寮区]────[礁滩·搁浅点(出生)]
```

1. **礁滩·搁浅点**：破渡船、暗礁、潮汐线残留物。教学：移动/互动/第一条文书。
2. **石堤·渔寮区**：三间渔寮、晾网架、堤门（锁）。教学：潜行 + 视奸#1（必须视奸巡堤人才能看到钥匙挂在哪间渔寮）。
3. **村中心**：晒盐场、水井、祠堂废屋、广播站（循环播放三年前台风警报）。多敌人潜行区。
4. **潮母宫**：祭坛、三炷倒香、祭文残页。谜题：视奸#2（切入祭师视野看他反复演练的点香顺序），按顺序点香 → 取回喉铃 → **触发血潮**。
5. **灯塔·沉船湾**：血潮后水位上涨，低路被淹，需沿沉船龙骨与高堤行进。歌唱者在此区游荡。终点：灯塔顶。

## 四、20 分钟节拍表

| 时间 | 节拍 | 内容 |
|---|---|---|
| 0–2 min | 开场演出 | 黑屏潮歌 + 电台残响 → 礁滩醒来。字幕交代。文书①（姐姐的信）。目标：进村。 |
| 2–5 min | 潜行教学 | 礁滩→石堤，遇补网人（劳作型）。字幕教学 Shift 潜行。文书②（渔民日记）。 |
| 5–8 min | 视奸教学 | 堤门上锁。教学 Q 视奸 → 切入巡堤人视野发现钥匙在渔寮二。潜入取钥匙。文书③（盐工账本批注）。 |
| 8–11 min | 村中心 | 多敌人晒盐场潜行。广播站听录音（文书④·录音稿）。获知：要止潮须去潮母宫补完锁潮祭。 |
| 11–14 min | 祭坛谜题 | 潮母宫。视奸祭师得到点香顺序，按序点三炷倒香 → 祭坛开，取喉铃。文书⑤（祭师忏悔文）。 |
| 14–16 min | 血潮高潮 | 取铃即血潮上涨：水面变暗红、上升淹没低路，全村潮尸起身巡游，歌唱者入场。空间规则改变：必须走屋顶木板与高堤。文书⑥（小满的歌词册，宫后廊）。 |
| 16–19 min | 逃向灯塔 | 躲避歌唱者（共鸣机制），穿沉船龙骨。文书⑦（灯塔看守日志）。灯塔下拉闸恢复供电。 |
| 19–20 min | 终局 | 灯塔顶敲响喉铃 → 海面浮现潮母真身剪影（山一样的轮廓，无数灯笼是它的鳞）→ 歌声灌入喉咙 → 强制视奸：从海的视角看见灯塔上的自己 → 字幕："你也开始唱了。" → **Demo 结束**。文书⑧（观测站电报，灯塔顶，可选）。 |

失败态：溺毙 → 检查点重试（每区入口 + 关键事件后自动存档）。

## 五、文书清单（8 条）

1. **姐姐的信**（礁滩·行李箱）——引入，警告。
2. **渔民日记**（渔寮一）——永涨潮第一夜的记录。
3. **盐工账本批注**（渔寮三）——"盐晒不干。盐是潮母的鳞。"
4. **广播站录音稿**（广播站）——三年前台风警报中断处，混入了潮歌。
5. **祭师忏悔文**（潮母宫偏殿）——闫守潮自述改祭文赎女。
6. **小满的歌词册**（潮母宫后廊）——潮歌歌词，暗示"歌者不是她，是借她喉咙的东西"。
7. **灯塔看守日志**（灯塔底层）——最后一个"活人"的记录：他不敢眨眼，因为一眨眼村民就换了姿势。
8. **观测站电报**（灯塔顶·可选）——外界早已把此海域除名，"盐门村：查无此村"。

## 六、技术选型

**Three.js (WebGL2) + Vite + 原生 WebAudio，零二进制资产（全程序化生成）。**

理由：
- 本云端环境无显示服务器，Godot 编辑器/导出验证链路长且难以实机验证；Chrome 已装，Three.js 方案可以用无头浏览器逐帧截图 + 注入输入做真实试玩验证。
- 程序化几何 + Canvas 生成贴图（含法线图）+ WebAudio 合成音频，可以把仓库保持为纯文本，同时达到 PS3 级观感（ACES 色调映射、级联阴影、指数雾、Bloom、暗角、胶片颗粒、色差、水面菲涅尔着色器）。
- 一条命令运行（`npm run dev` / 或构建后任意静态服务器），键鼠输入天然支持。

### 6.1 代码结构

```
src/
  main.js            入口 / 主循环
  core/engine.js     渲染器、后处理链、resize
  core/input.js      键鼠 + 指针锁定
  core/audio.js      WebAudio 程序化合成（海床/潮歌/电台/脚步/发现音/铃/心跳）
  world/textures.js  Canvas 程序化贴图 + 法线图生成
  world/materials.js 材质库
  world/water.js     水面着色器（血潮切换）
  world/village.js   五区大地图构建 + 碰撞体 + 巡逻路点
  world/sky.js       天空穹顶/雾/粒子
  entities/humanoid.js 程序化人形（分层骨架+程序动画）
  entities/enemy.js  潮尸 AI 状态机
  entities/player.js 第一人称控制器
  systems/sightjack.js 视奸
  systems/stealth.js 可见度/噪音模型
  systems/story.js   节拍/触发器/检查点/文书数据
  ui/hud.js          字幕/目标/文书阅读/暂停/滤镜
```

### 6.2 性能预算

- 目标 60fps（1080p，集显可 30fps）；draw call < 300（合并静态网格）；点光 ≤ 12 盏同屏（灯笼用发光贴图 + 少量真实点光）；阴影仅主平行光 2048。
- v1.1 新增的全部渔村杂物（11 种套件、上百件）走静态合批，芦苇 760 株走 InstancedMesh（1 draw call），密度翻倍不破预算。

## 七、v1.1 升级记录（美术精度与恐怖感）

- **贴图管线 v3**：每张贴图从三件套升为**颜色/法线/粗糙度/AO 四件套**；AO 用双尺度凹腔法
  从高度场推导（小半径抓缝隙刻痕，大半径抓整体起伏的背光坑），全部材质接入 `aoMap`。
- **潮尸皮肤**：升 `MeshPhysicalMaterial`——clearcoat 湿膜高光 + sheen 尸蜡感；
  纹理层新增藤壶环带与皮下淤青；分辨率提到主视觉级 1024²。
- **人形建模 v3**：锁骨、眉弓、颧骨、耳廓、肘/腕/膝/踝骨点、隔湿衣顶出的脊椎结节、
  颈侧藤壶簇、肩缝湿海藻缕；歌唱者独有束腰红带垂穗 + 框脸鬓发；村犬贴皮肋线/垂耳/垂尾。
- **场景密度**：木桶/陶缸/竹篓/板凳/柴堆/缆绳圈/橹/咸鱼架/蟹笼/浮木/海藻堆 11 种杂物套件
  按区布置；积水洼镜面；电线杆 + 悬链电线（接进广播站天线）；三处炊烟（没人做饭，火没灭过）；
  坟茔坡（旧坟歪碑 + 三座无字新坟 + 一个挖空的坑）；芦苇加密至 760 株并服务潜行机制。
- **水面 v3**：月光碎波带（与天空月位对齐，血潮翻成暗红"鳞"）+ 离岸二道碎浪白。
- **后处理**：片门抖动（24 格/秒亚像素画框浮动）+ 镜头水痕（血潮/溺水时水爬镜片带折射）。
- **玩法**：芦苇隐蔽、近身喉音、掐喉抓捕演出（详见 2.4）。
