# 《返潮》(FANCHAO) M01 垂直切片 设计文档

> 本文档对应本仓库的可玩 Demo：蚀湾「迎宾楼」千禧婚宴酒店，一夜。
> 世界观与视觉遵循《返潮》Canon（PROJECT_CONSTITUTION / ART_DIRECTION / DEPTH_SYSTEM / F01_HERO_MONSTER）。

## 一、世界观

### 蚀湾（2003）

2000 年前后的中国沿海小城。它经历了**第二次失去**：

- 第一次是海收走的——风灾、沉船、讨海人的旧账；
- 第二次是人自己退的——水产公司改制解散，千禧内湾填海工程中止
  （三座桥墩建成即废弃），年轻人外流，房子卖不掉，共同记忆没有下文。

海退了三年，今年又漫回来。镇上把这叫**返潮**：
东西受了潮，**本应结束的事，就会重新走一遍**。
返潮不是复仇，不是诅咒——是一段本该告别的关系拒绝结束。

### 迎宾楼

原水产公司招待所，九十年代末装修成婚宴酒店赶「千禧婚潮」，
2003 年列入第三批拆除范围。楼里还有四个员工在上班：

| 岗位 | 姓名 | 排班终止日 |
|---|---|---|
| 前厅 | 苏凤英 | 十月十五日 |
| 保卫 | 秦国栋 | 十月二十日 |
| 后厨 | 黄有德 | 十月二十四日 |
| 维修 | 王承海 | **（无终止日期）** |

### 主角与事件

玩家是新娘**林小满**的弟弟。姐姐的婚宴定在 10 月 25 日迎宾楼，
她没有出席自己的婚礼——镇上说她"跑了"。拆迁前最后一夜，你进楼找她留下的东西。

真相（由 8 件文书拼出）：小满在婚期前离开了蚀湾——她的告别方式是放手。
而维修工王承海的告别方式，是把一切"收好"：婚纱照擦了又擦摆回原位、
四十桌的席永远铺着、同一张进货单写了三遍、登记簿上同一场婚宴登记了四遍。
**失踪的人不是被杀死的，是被「保存」起来的。**

### 主题

- **保存 vs 占有**：留住 ≠ 爱。把人收进柜子里的告别不是告别。
- **叙事空洞**：没有下文的工程、没有办成的婚宴、没有说出口的再见——空洞会自己长东西。
- **告别伦理**：结局不是打败怪物，而是把姐姐**自己写下的告别**（那封信）带出这栋楼。

## 二、物理核心：Depth（深度系统）

遵循 DEPTH_SYSTEM_CANON，本切片落地三条：

1. **内部大于外部**：客房走廊图纸 12.6m → 实测 21.9m → Leak 后 34.0m。
   F01 本人：表面 0.4m，内部 3.8m。
2. **听潮 / 测距**：
   - **工程深度尺**（保卫室拾取）：对着平面图测量，读出"图纸与楼不一致"；
   - **听潮**（下述核心机制）：借他者的眼睛感知结构。
3. **Local Depth 规律可学习**：
   - 变深永远发生在**你背后**（折返触发走廊延伸，回头才看见）；
   - 镜子先于现实（镜里灯数 ≠ 身后灯数、镜里走廊更长）；
   - 录像先于现实（超前十八秒）；
   - 深处的门牌没有数字、灯不亮。

## 三、核心机制

### 3.1 听潮（原「视奸」的语义迁移）

按 `Q` 借入附近载体的眼睛，本体静止且失明。载体分三类：

| 载体 | 视野特征 | 暴露倍率 |
|---|---|---|
| 员工（苏/秦/黄） | 疲惫浑浊、随呼吸起伏、FOV 70 | 0.5 |
| 监控摄像头（大堂/走廊） | 冷绿不眨眼、广角 88、可缓摇 | 0.15 |
| F01 王承海 | 最冷最清楚、像从井底朝上看、FOV 62 | **1.6** |

**收益**：侦察巡逻路线、房间结构、Depth 异常；监控信道可提前看到宴会厅录像画面。
**代价（暴露槽）**：听得越久涨得越快，F01 信道最快；涨满触发**反向听潮**——
他借走你的眼睛 3.2 秒，然后他永远知道楼里有人。
**表现禁则**：切入是水压、耳鸣、呼吸、桶形畸变——明令禁止 VHS 噪点/扫描线。

### 3.2 潜行

- 员工 AI 状态机：劳作/巡逻 → 起疑（黄表）→ 追踪（红条）→ 最后目击点搜索 → 归位。
- 视锥 + 视线遮挡 + 听觉半径；噪音事件总线（脚步/前台铃/碰倒物品）。
- 地面材质影响噪音：地毯（走廊/婚宴厅/大堂红毯）上脚步更轻。
- 员工抓到你＝"扭送出门"（回检查点）；**F01 抓到你＝被保存**（井演出后回检查点）。

### 3.3 F01「井身者」王承海（Hero Monster）

- **6m 读取**：他只是一个还在上班的中年人。灰蓝工装、暗红领、深色化纤裤、旧皮鞋、
  侧分短发。他会先侧耳——在你看清他之前，他已经知道你在哪。
- **2m 读取**：深度尺读数「表面 0.4m / 内部 3.8m」。左眼、右眼、口腔各是一口
  **真实向内的井**：井口窄、井腹宽（几何上"里面比外面大"），井壁一圈圈往下退，
  最深处有一线不该存在的水光。**不是黑贴图，不是发光眼。**
- **追逐**：他不跑。比走路快一点、比跑慢一点，像去接一个客人。
  追逐中玩家身后走廊的灯**一盏盏灭掉**（空间压迫）。禁止僵尸跛行/抽搐/尖叫冲刺。
- **抓捕演出**：他把你的头捧起来（"不重。很稳。"），镜头沉进他左眼的井——
  死亡结算词是一个字：「**井**」。
- **永不忘记**：追逐失败重来后，他回婚台继续擦桌，"像什么都没有发生。可他记得你。"

### 3.4 非怪物恐怖：婚宴录像超前现实

宴会厅的电视车接着录像机，与保卫室监控共用一路 RTT 画面。
播放后屏幕显示**这间厅十八秒之后的画面**：一个灰蓝工装的人走进来、
停在婚台前、转头看镜头（= 看你现在站的位置）。带子放完 18 秒后，
现实里的 F01 从门口进来，**沿同一条路径把动作原样重演**。
实现：幽灵 F01 渲染在 layer 2（只有录像机位相机可见）→ 18 秒后实体 F01 脚本化行走。

### 3.5 文书 / 检查点

8 件文书：登记簿、拆迁公告、排班表、保卫日志、进货单、剪报（内湾工程中止）、
楼层平面图工程注记、新娘的信。检查点 4 处：前庭 → 大堂 → 走廊 → 婚宴厅。
死亡回最近检查点，世界状态按 flags 幂等恢复（门开闭/走廊深度/员工在场/F01 岗位）。

## 六、验证矩阵

- `smoke`：标题 → 进入 → 各厅室传送截图（前庭/门廊/大堂/前台/保卫室/走廊/后厨/婚宴厅/舞台）。
- `looks`：员工三人外观、F01 六米/两米/井特写（断言三口井存在）、六大场景、
  监控信道画面、压力锋面（灰绿海雾），FPS 采样。
- `gameplay`：听潮进出与换台、员工警觉→被抓→重生、文书拾取、
  F01 六米/两米读取回调、走廊变深、暴露槽上涨。
- `playthrough`：按节拍表逐 flag 断言直至结局遮罩（含被 F01 抓住的井演出与重生后带信逃脱）。

## 七、诚实边界

程序化管线无法生成真 PS5 级网格/扫描资产。本切片达成的是
**《死魂曲》式可读精度 / 主机世代观感目标**：远看是一个还在上班的中年人，
近看五官解剖轮廓可读、井是真实向内的多层深度几何。文档与宣传不得宣称真 AAA 资产。
